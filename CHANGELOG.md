# Changelog

## v0.26.0 (in progress)

### Added
- `Tempest.Calc.*` module family: transparent worksheet engine, sheets, library, verification (ADR-0165). Engine: unit-aware expressions over a runtime SI dimension vector, step log (formula → substitution → result), caps, seeded Monte Carlo, tornado sweeps. Sheets: the one §3.4 sheet shape, validation, CSV/JSON exchange. Library: calculation instances with provenance, Evidence-governed Check/Issue in one transaction, Calculation-register link, calc packs, stale marker.
- `IEvidenceService.IssueInOneTransactionAsync`: the issue sheet bytes, attachment, issue record and status commit together; the Workspace issue command uses it.
- Desktop: **Worksheets** node under Modules → Calculations with the shared worksheet form (live recalculation, unit pickers, provenance per input, governing-check bar, Show working, read-only issued instances); calc-sheet PDF renderer; TrueType glyph subsetting for every PDF (issue sheet 222 → 162 KB).
- Mechanical worksheets: M1 `mech.tolerance-stack` v2 (WC, RSS, modified RSS, distributions, C_p/C_pk/DPMO/yield, Pareto, Monte Carlo, GD&T contributors, BS 8888/ASME notation); M2 `mech.iso286-fit` (ISO 286-1 formulae), `mech.press-fit`, `mech.thick-cylinder` (migrated); M3 `mech.bolted-joint` (simplified VDI 2230), `mech.bolt-group` (elastic method). Each with known-answer, property, robustness and golden tests, a spec under `docs/calcs/`, and two worked examples under `docs/worked-examples/`.
- Structural worksheets: S1 `struct.section-properties` (parametric shapes with fillets, polygon with holes, composites; Green's theorem, plastic moduli, torsion, warping; Blue Book UB/SHS within 0.5 %); S2 `struct.frame-2d` (direct stiffness 2D frames: releases, springs, cases and combinations, envelope, caps 2,000 nodes / 4,000 elements / 50 cases) and `struct.beam-formulas` (Roark single-span library); S3 `struct.en1993-member` (EN 1993-1-1 tension, compression, flexural buckling, bending, shear, simplified interaction; clause numbers only, editable imperfection and partial factors). Same DoD as the mechanical set.
- Building-services worksheets: B1 `bs.pipe-pump` (Darcy–Weisbach, Colebrook with Swamee–Jain check, K and equivalent-length fittings, system curve, pump duty point, affinity laws, NPSH; water correlations Kell/Vogel/Hyland–Wexler); B2 `bs.psychrometrics` (state from any second property, sensible/cooling-dehumidification/steam/evaporative/mixing processes, chart series); B3 `bs.duct-sizing` (equal-friction and velocity methods, round/rectangular/flat-oval equivalent diameters, fittings by user coefficients, index-run totals, limit checks). Same DoD.
- Electrical worksheets: E1 `elec.motor-sizing` (linear and rotary loads through screw / belt / rack / gearbox, trapezoidal and S-curve profiles, peak and RMS torque, inertia ratio, candidate-motor checks); E2 `elec.enclosure-heat` (heat-load schedule, effective surface by face exposure, editable heat-transfer coefficient, natural rise, forced-ventilation airflow with altitude correction, fan duty point, solar gain, cooling-unit capacity); E3 `elec.voltage-drop` (DC, single- and three-phase from resistivity, R/X per km or mV/A/m; parallel conductors; loss; conductor temperature estimate; user limits, BS 7671 cited not embedded). Same DoD.

### Changed (Phase 7 — Black/Blue, ADR-0166)
- Desktop worksheet form: *Import inputs (CSV/JSON)* re-seeds the form from the clipboard (a worked example's `inputs.json` or the exported CSV), carrying table and vector inputs the form has no field for; every import notice is shown and a blocking one imports nothing.
- Check and CheckPack refuse a draft whose inputs lack provenance; a Rejected check stays on the instance and leaves the Evidence Draft; empty checker, organisation, issue reference and client are refusals.
- Sheets: table inputs are written row by row (up to 100 rows); utilisation checks read `u = 0.375 vs u ≤ 1`; valid ranges follow the entered unit; a non-optional input that takes its template default raises a warning naming the default.
- JSON import: duplicate symbols and ValueText-only values are refused by name; a malformed document is described in plain words.
- PDFs: the font subsetter keeps only the tables a PDF needs, so Windows's default face embeds at the same size as the brand faces.

### Security (Phase 6 — Red/Blue)
- Imports: duplicate CSV headers, quoted-cell length, sign-prefixed DDE formulas, null JSON entries and null table rows are refused with notices (never exceptions); provenance reference/revision capped at 200/40 characters; validator notices capped per input.
- Engine and solvers: variadic reducers bounded before allocation; calculator Monte Carlo capped at 100,000 samples; frame solver bounded per member (200 loads) and by factor work.
- Library and Core: optimistic concurrency on every instance write; Check and Issue commit with the instance in one transaction with a transaction-time status re-check; issued records compared in full before a Superseded mark is accepted; Revise atomic and recoverable; pack members frozen after the pack check.
- PDF: every drawn string cleaned of control, separator and format characters and capped per field and paragraph.

### Addendum B
- B-0 foundations. Fluid Power is the fifth calculation discipline (`CalcDiscipline.FluidPower`, appended so no template hash changes) and a discipline in the `ADR-0163` registry (Circuit, Actuator and Power unit Kinds with typed attributes, no design-code check); assembly `Tempest.Calc.FluidPower` and test project `Tempest.Calc.Tests.FluidPower` with the common definition-of-done checks (ADR-0170).
- W3 material property library on the reference records: E, G, ν, ρ, α, λ, f_y, f_u, R_m(d) coefficients, permissible strains, secant-modulus points and friction pairs, with temperature tables read linearly (never extrapolated); every value carries its own source, edition, page or table, licence class, who entered it, when and an evidence SHA-256; four generic indicative seed materials; a template input maps to a property and a calculation pins the material revision; one licensed value makes the whole material licensed and it never leaves through an export (§A5).
- Shared kernels: `GasLaw` (polytropic p·Vⁿ, absolute-pressure helpers; the B6 vessel uses it, sheet unchanged) and the tolerance-stack engine, both in `Tempest.Calc.Engine` (M1 uses the engine, sheet and golden unchanged).
- Licensed values now stay withheld wherever they travel: a value linked from a calculation that holds an input pinned to a licensed record (through any depth of links, also a table cell) is withheld from the inputs export and printed on the issued sheet as the link and "value derived from a licensed record — withheld"; a licensed value in any record kind makes the record licensed.
- Opus review fixes: the issued sheet credits each material value to its own source; a temperature always carries its unit; a unit-free property no longer goes stale when applied; malformed material files are refused, not crashes; an exported seed keeps its indicative flag; the gas-law accumulator form refuses a pre-charge above the low pressure; the stack engine checks the contributors it is given; the cross-discipline test lists include Fluid Power.

### Addendum A — twelve more calculators (no tag)
- Reference records (§A3, DA-05): tabulated values carry source, edition and amendment, table or clause, licence holder, who entered them and a licensed-source flag; revisioned, pinned by the calculations that use them; a revised record makes them stale. Values from a licensed record are withheld from every export (DA-06).
- L1 result linking (ADR-0168): an input links to another calculation's output, pinned to its revision; output ports; dimension, cycle and 20-link checks; staleness runs through the whole chain and blocks Check, Issue and pack issue; "Update to revision n" re-pins (a checked or issued calculation as a new revision); pack templates build a linked pack issued as one Evidence bundle; the worksheet form links an input and shows the stale marker.
- M5 rolling bearing life `mech.bearing-life` (ISO 281:2007, ISO 76:2006): duty cycle, a₁ by the 2007 Weibull form (1990 values stated), a_ISO capped at 50, κ < 0.1 hard FAIL, κ > 4 treated as 4; ratings, X/Y/e and a_ISO as records.
- S5 EN 1990 load combinations `struct.load-combinations`: 6.10 or 6.10a/6.10b, SLS 6.14b/6.15b/6.16b, accidental 6.11b; every variable action leads in turn; max/min envelopes (DA-07).
- B5 heat exchanger `bs.heat-exchanger`: ε-NTU rating and sizing for counterflow, parallel, 1-2 shell and tube, crossflow (approximate) and C_r = 0, with LMTD and F as a cross-check.
- E6 load budget `elec.load-budget`: demand per bus, heat to E2, PSU with derating, transformer with a starting-peak check, battery with derates and optional Peukert; the engine gains VA and var (DA-09).
- B6 sealed system `bs.sealed-system`: emitter outputs by the characteristic equation and the expansion vessel (Kell density, DA-10).
- The worksheet form applies a reference record to a draft and saves tabulated inputs as a new record (licensed flag included).
- E5 fault protection `elec.fault-protection`: Z_s at conductor temperature, Z_s,max from C_min·U₀/I_a (MCB B/C/D or user-read time–current points), disconnection time, adiabatic CPC and line checks with derived k, simplified fault level; every input hard-limited; independent check demanded (DA-12).
- M6 weld group `mech.weld-group` (elastic line method) on a group-geometry kernel now shared with the M3 bolt group.
- M4 shaft `mech.shaft`: two-plane bending through the S2 solver, DE-Goodman and yield at marked sections (Marin factors by published equations), slopes and deflections against limits, Rayleigh and Dunkerley critical speeds, parallel keys (DA-13).
- Drive-train pack template (E1 → M4 → M5 → M2) with linked values and transitive staleness (DA-14).
- Templates can demand an independent check: Check and CheckPack refuse the calculation's author (DA-12).
- S4 bolts and fillet welds `struct.connection-ec3` (EN 1993-1-8): shear, bearing, tension, punching, combined, block tearing, spacing minima, simplified and directional weld methods; stress areas by the ISO 898-1 formula; every input hard-limited.
- **Bolt shear scope (ADR-0169):** the v0.25.2 bolt-shear module is the shank-in-plane case of EN 1993-1-8 Table 3.4 (gross area, α_v 0.6 for every class); its picker, description and assumptions now say so, classes 4.8, 5.8 and 6.8 are added, and threads in the shear plane go to the S4 worksheet. Values are unchanged for existing classes.
- E4 conductor sizing and overload coordination `elec.conductor-sizing`: design current from output power, device from the user's ratings record, conductor from the user's ampacity record (none ship), I_b ≤ I_n ≤ I_z and I₂ ≤ 1.45·I_z with deemed conditions for gG and semi-enclosed fuses, derived C_a approximation and AWG geometry; every input hard-limited; independent check demanded (DA-19).
- B4 U-value and room heat loss `bs.room-heat-loss`: series-resistance U per element (agrees with `calc.plane-wall-heat-transfer` to 1e-9), fabric, thermal-bridge and ventilation loss with MVHR and infiltration, HLC and target-U checks; feeds B6 (DA-19).
- S6 column base plate `struct.base-plate` (EN 1993-1-8): bearing strength and effective area for I/H, RHS and CHS columns, Table 6.7 moment statics in three regimes, T-stub modes, friction plus anchor shear, the plate thickness that satisfies every check; anchorage designed externally in PROFIS and attached as Evidence from the worksheet form; every input hard-limited; independent check demanded (DA-20).
- Table-cell links (ADR-0168 amendment 2): a number or quantity cell of a table input links to another calculation's output, with the same pinning, staleness, cycle and dimension rules as input links; a table pinned to a reference record cannot take one; a stale read-to-write is refused rather than overwritten (DA-21).
- Wet-heating pack (B4 rooms → B6 → B1 → E1): B6 gives the loop drop and mean water temperature; B1 derives its flow from a heat load and gives the pump shaft torque and speed; E1 gains a continuous-duty mode (load speed, run-up time, continuous power) for pumps and fans.
- Cooling (E6 → E2 → B5 → B1) and steel-support (S5 → S2 → S3, M3 → S4a; S4b → S6) packs; drive train extended to M3; built-in packs carry example inputs; five issued pack worked examples under docs/worked-examples/packs (DA-22). A refused pack stores nothing (dry run).
- Desktop worksheet form: a saved-calculations list (open, stale mark) and a calculation-packs panel (create from template, open members, check by the signed-in person, issue).
- Review fixes (Addendum A Security, Red, Green, Black; Purple verified): issued sheets withhold a licensed table's rows; no check or issue on a draft upstream; staleness passes through records and templates at every depth; independent check refuses everyone who edited the inputs; evidence references must resolve; CSV keeps tables and blocks a withheld value until the record is applied again; new sheets open on declared defaults and say what to enter; E4 carries its device to E5; E1 RMS power; E6 panel-heat shares; B5 constant-temperature stream; B4 target U on external elements; M5 axial factor; weld and bolt groups use the product moment (DA-23, DA-24).
- Owner test pack `docs/testing/v0.26.0-owner-test-pack.md` and the handover's Addendum A section; §A9 gates met — READY FOR OWNER TESTING, not released, not tagged.
- Motor-circuit pack template (E1 → E6 → E4 → E3 / E5 → E2) issues as one bundle; a licensed ampacity record stays out of every export; a pack refused for a blocked step says which step and why.
