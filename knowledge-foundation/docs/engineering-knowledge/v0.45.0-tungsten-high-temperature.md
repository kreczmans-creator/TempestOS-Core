# v0.45.0 — Tungsten High-Temperature Behaviour

This release adds the high-temperature engineering layer for tungsten systems.

## Coverage

The library now captures the engineering controls for:

- creep
- recrystallisation
- high-temperature strength retention
- oxidation
- thermal gradients/cycling
- carbide hot hardness
- binder-phase stability
- tungsten-copper thermal mismatch

## Why this matters

Tungsten is not adequately represented by room-temperature tensile strength,
density and modulus. Service temperature, time at temperature, processing
history and atmosphere can change the governing failure mechanism.

For this reason the library separates:

**instantaneous strength → creep → recrystallisation → environmental degradation**

rather than collapsing all high-temperature behaviour into a single derating
factor.

## Evidence boundary

This pass establishes the engineering model and screening layer. It does not
create design allowables. Grade-level authoritative evidence remains required.
