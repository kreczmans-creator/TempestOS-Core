# v0.43.0 — Tungsten Fundamentals

The tungsten family is now populated using the established material-library
ontology.

## Coverage

The first pass deliberately separates materially different systems:

- commercially pure tungsten
- tungsten-rhenium alloys
- tungsten-copper composites
- tungsten carbide
- lanthanated tungsten

Each initial record covers composition, density, melting point, elastic
properties, thermal/electrical behaviour, mechanical behaviour, manufacturing,
machinability, environment, cost, availability and uses.

## Engineering distinction

Tungsten should not be treated as a single conventional structural metal.
Temperature, processing route, recrystallisation, ductile-brittle transition,
porosity and grade chemistry can dominate engineering performance.

Tungsten carbide is modelled separately from metallic tungsten because its
hardness, brittleness, binder phase and manufacturing route make it a distinct
engineering material system.
