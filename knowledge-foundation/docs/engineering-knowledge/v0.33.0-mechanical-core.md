# v0.33.0 — Mechanical Core Population

## Purpose

v0.33.0 populates the first universal mechanical fundamentals across the
16 priority steel grades already established by the Steel Fundamentals Audit.

The populated screening layer covers:

- density
- yield strength
- ultimate tensile strength
- elastic modulus
- Poisson's ratio
- shear modulus
- hardness
- elongation/ductility

## Engineering control

These are **reference ranges / typical engineering values**, not certified
design allowables. Exact values depend on specification, product form,
thickness, heat treatment, test direction, temperature and processing history.

Where shear modulus is supplied as a reference value, it is consistent with
the isotropic relationship G = E / [2(1 + nu)] for the stated E and nu.

## Status

The universal mechanical-core *categories* are now populated for all 16
priority grades. Exact condition/product-form coverage remains a separate
evidence-population task.

No value in this release is approved for design solely because it is present
in the knowledge library.
