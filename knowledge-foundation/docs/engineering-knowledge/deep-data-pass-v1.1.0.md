# Engineering Knowledge Foundation v1.1.0

This release moves the catalogue from material-level records toward **state- and observation-level engineering data**.

Added:
- material-state register for temper/heat treatment/product form/reference temperature;
- chemistry screening records;
- property-observation examples with source attachment fields;
- designation mappings with confidence and warnings;
- machine-readable validation fixtures.

Governance path:
`candidate → sourced → reviewed → verified → approved_for_design`

Current numeric catalogue data remains `candidate_reference` / `screening_only`. Promotion is a governance action, not an automatic import consequence.
