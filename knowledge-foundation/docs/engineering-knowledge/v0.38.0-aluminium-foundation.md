# v0.38.0 — Aluminium Foundation

The aluminium family has now been started using the same controlled ontology
established by the steel baseline.

## Initial population

The first priority set covers commercially pure aluminium, 2xxx, 5xxx, 6xxx,
7xxx and representative cast/additive aluminium families.

Each populated alloy record carries:

- designation/family
- reference temper
- density
- yield and tensile strength
- elastic modulus and Poisson's ratio
- thermal conductivity
- coefficient of thermal expansion
- specific heat
- electrical resistivity
- relative cost
- general availability
- common uses
- environmental considerations
- manufacturing/process considerations
- common standards/test frameworks

## Evidence control

All populated numeric values are engineering-reference screening values.
Temper, product form, thickness, processing history and exact specification
remain mandatory dimensions for design-quality evidence.

No aluminium record is approved for design merely by being populated.
