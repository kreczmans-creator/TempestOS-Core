# Engineering Knowledge Foundation v0.7.0

## Catalogue expansion

This pass completes the next major steel-family expansion and starts the aluminium family.

### Steel additions

- 304 / 316L / 321 austenitic stainless
- 17-4 PH / 15-5 PH precipitation-hardening stainless
- 440C martensitic stainless
- H13, D2, O1 tool steels
- 51CrV4 and SAE 9255 spring steels
- Hardox 450 wear-resistant plate
- P355NH pressure-vessel steel
- Maraging 250 ultra-high-strength steel

### Aluminium additions

- 1050A
- 5083-H111
- 6061-T6
- 6082-T6
- 6082-T651
- 7075-T6
- 2024-T3
- 2014-T6

## Data status

All newly populated numeric values remain `candidate_reference`.

The catalogue is for engineering knowledge discovery and architecture development. Exact design calculations require condition-specific, source-verified values.

## Engineering principle

The database must be able to answer both:

1. "What is this material?"
2. "What value is defensible for this material **in this exact condition and application context**?"

The second question is the long-term target.
