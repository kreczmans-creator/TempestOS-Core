# Engineering Knowledge Foundation v0.28.0

## Steel condition and property depth

### 410 / 420
The physical-property layer is now populated from the Outokumpu Dura range for 410/4006 and 420/4021:
density, elastic modulus, CTE, thermal conductivity, thermal capacity and electrical resistivity, all with the stated 20 °C/reference interval context. Both are identified as magnetizable.

### 440C
BÖHLER N695 source data now provides density, modulus, thermal conductivity, specific heat and specific electrical resistance at 20 °C. The product remains explicitly tied to the manufacturer's long-product context.

### 13-8 Mo
H1150 and H1150M longitudinal datasets are now represented separately. H1150M includes Charpy impact values at room temperature and at -73, -115 and -195 °C. This demonstrates why condition and test temperature must be part of the data model.

### 15-5 PH
H1150-M is added to the condition matrix, including UTS, yield, elongation, reduction of area and hardness.

### Fatigue/fracture architecture
A formal schema is now in place for fatigue and fracture-toughness records. The schema requires test/environment/specimen context so later data cannot accidentally be collapsed into a misleading generic value.

All new records remain `sourced` + `reviewed`, not design allowables.
