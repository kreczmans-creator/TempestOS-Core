# v0.42.0 — Aluminium Baseline Freeze / Tungsten Start

## Aluminium

The aluminium library has passed its fundamentals coverage audit.

The baseline explicitly covers designation/composition, temper, product form,
mechanical, thermal, electrical, environmental, manufacturing, joining,
shear/bearing, fatigue, fracture, temperature dependence, standards,
commercial information and provenance.

This is a foundation freeze, not a declaration that every numerical value is
design-qualified. The quantitative layer remains screening-only until
authoritative source linkage is completed.

## Provenance

A formal authoritative-source contract has been added. Future verification
must preserve source revision, alloy/temper/product form, test method, units,
conditions and page/clause traceability.

## Tungsten

The tungsten family has been started with an explicit scope and ontology.
Tungsten metal, heavy alloys, carbide, copper composites, W-Re and
lanthanated tungsten are deliberately separated because their engineering
behaviour and use cases differ materially.

## Next

Populate the tungsten fundamentals using the established material ontology,
then build its mechanical/thermal/electrical/standards/commercial layers.
