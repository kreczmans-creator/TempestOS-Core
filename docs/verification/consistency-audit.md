# Calculator consistency audit

Scope: all 25 engineering calculators on release/v0.26.0 (mechanical 9, structural 6, electrical 5, building services 5). This is a findings list only. No product code was changed.
Method: I read all 25 calculator sources, the two sheet renderers, the catalogue code and the 25 spec docs. I ran the Probe tool on empty inputs and on each calculator's first known-answer case.
Evidence base: 398 inputs, 137 block and warning messages, 96 applicability rules, 81 assumptions, 80 clause references and 41 output ports.
Result: 60 findings in 12 categories. Calculator names below omit the discipline prefix, so `bearing-life` means `mech.bearing-life`.

## Priority

Fix first. These could mislead an engineer.

1. Row 19. Section properties and member checks use opposite names for the major axis. A copied `W_pl_x` could be read as the minor axis.
2. Rows 10 to 12 and 14 to 17. The same symbol means different things across linked sheets. Examples are `theta`, `T`, `t_f`, `eps`, `h`, `P`, `p_i`.
3. Rows 20 to 28. Linked quantities use different units. Torque is N·m in drive sizing and kN·m in the shaft. Flow is m³/s and m³/h. Resistivity differs by a factor of one million.
4. Row 28. Percent appears as a unit, as a bare 0 to 100 number and as a 0 to 1 fraction. A wrong entry would pass the range check.
5. Rows 34 and 35. Severity is not consistent. A broken limit can appear only as a warning. Declared and emitted severities disagree.
6. Rows 3 and 4. Yes/no checks print utilisation 0. Default notices bury real warnings.
7. Rows 45 and 55. Sheets cite codes such as E4, S6, M3 and §A5 that an engineer cannot resolve.
8. Rows 29 and 30. Over-precise or noisy numbers suggest accuracy the method does not have.

Cosmetic. These can wait.

- Rows 1, 2, 8, 9: heading case, result order, description style, optional hints.
- Rows 5 to 7: wording of modulus, strength and limits.
- Rows 38 to 42: group names, group order, soft limits.
- Rows 47 to 54: titles, categories, scope length, method layout, clause style.
- Rows 56 to 60: assumption form, repeated limitations, spec doc labels and titles.
