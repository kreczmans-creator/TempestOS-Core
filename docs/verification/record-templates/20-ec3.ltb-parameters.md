# 20 ec3.ltb-parameters

Kind: `ec3.ltb-factors` (imperfection factors and 6.3.2.3 parameters).
Status: existing CalcRecordKind `ec3.ltb-factors`
Planned name: `ec3.ltb-parameters`. The built calculator names the kind `ec3.ltb-factors`. The file name stays.

## Used by
- S7 lateral-torsional buckling and N+M (built, `struct.ltb-interaction`) lists all seven symbols for this kind.
- S7 ships with default values for these inputs. A record replaces the defaults and cites its source.

## Symbol mapping
- Each header is the symbol of an S7 input. The importer fills the input with the same symbol.
- Enter one row for each National Annex. The file holds a scalar set, so it has one data row.

## Copy from
- Type the imperfection factors for the buckling curves from your copy of EN 1993-1-1, Table 6.1.
- Type lambda_LT0 and beta_LT from the National Annex to BS EN 1993-1-1, clause 6.3.2.3(1).
- Confirm every table and clause number against your copy.

## Columns
- `alpha_a0[-]`: imperfection factor for curve a0.
- `alpha_a[-]`: imperfection factor for curve a.
- `alpha_b[-]`: imperfection factor for curve b.
- `alpha_c[-]`: imperfection factor for curve c.
- `alpha_d[-]`: imperfection factor for curve d.
- `lambda_LT0[-]`: plateau slenderness of the rolled-section LTB curve.
- `beta_LT[-]`: shape factor of the rolled-section LTB curve.

## Edition to record
Record the National Annex edition and amendment. Record the edition of the Eurocode part it modifies.

## Importer checks
- Reject any blank or non-positive number.
- S7 refuses an alpha value outside 0.05 to 1, lambda_LT0 outside 0.2 to 0.5, and beta_LT outside 0.5 to 1.
- Warn when the alpha values do not rise from curve a0 to curve d.

## Maps to CalcDataRecord
Kind is `ec3.ltb-factors`. The importer saves one CalcDataRecord for the file.
Each column becomes one CalcDataValue with its Symbol, Number and Unit.
