# 10 en60204.ampacity

Kind: `en60204.ampacity` (BS EN 60204-1 current-carrying capacity).
Status: proposed — no CalcRecordKind yet; Track S confirms symbols when the calculator is built

## Used by
- E4 conductor sizing (planned) uses it for machine and control panel wiring.

## Copy from
- Type the values from BS EN 60204-1:2018, Table 6.
- Enter one table per file. Confirm the table number against your copy.

## Columns
- `method[text]`: installation method as the table names it, such as B1, B2, C or E.
- `csa[mm2]`: conductor cross-sectional area.
- `I_z[A]`: current-carrying capacity at the table's reference ambient temperature.

## Edition to record
Record the BS EN 60204-1 edition and any amendment or corrigendum. Note the reference ambient temperature in notes.

## Importer checks
- Reject any row with a blank or non-positive number in a numeric column.
- Reject a duplicate method and csa row.
- Within one method, csa and I_z must both rise.
- Warn when I_z is outside 1 to 5000 A.

## Maps to CalcDataRecord
Kind is `en60204.ampacity`. The importer saves one CalcDataRecord for the file.
One CalcDataValue with Symbol `I_z_table` holds Rows. Each CalcRow has one cell per column, keyed by column symbol.
