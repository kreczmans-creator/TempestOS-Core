# 10 en60204.ampacity

Kind: `cable.ampacity` (cable current-carrying capacities for one installation method).
Status: existing CalcRecordKind `cable.ampacity`
Planned name: `en60204.ampacity`. The built calculator names the kind `cable.ampacity`. The file name stays.

## Used by
- E4 conductor sizing (built, `elec.conductor-sizing`) reads this record into its `ampacity` table input.
- Set the E4 context to the machine wiring option when you apply it. The context changes the clause citations only.
- Template 04 fills the same kind from BS 7671.

## Symbol mapping
- The whole file becomes one value with Symbol `ampacity`. Its rows fill the `ampacity` table input.
- Each header is a column symbol of that table: `CSA` in mm^2, `AWG` with no unit, `I_t` in A.
- The planned column `I_z` is now `I_t`. E4 computes I_z itself from I_t and the correction factors.

## Copy from
- Type the values from BS EN 60204-1:2018, Table 6.
- Enter one table per file. One table means one installation method. Confirm the table number against your copy.
- Name the method and the reference ambient temperature in `table_or_clause` and `notes`.
- Give each file its own title label, such as `Title [method B2]`.

## Columns
- `CSA[mm2]`: conductor cross-sectional area. Leave it blank for an AWG table.
- `AWG[-]`: AWG gauge number n. Leave it blank for a metric table.
- `I_t[A]`: tabulated current-carrying capacity at the table's reference ambient temperature.

The old `method` column is gone. E4 does not read it. Put the method in the notes.

## Edition to record
Record the BS EN 60204-1 edition and any amendment or corrigendum.

## Importer checks
- Reject a row with a blank or non-positive I_t.
- Reject a row that fills neither CSA nor AWG.
- Reject a duplicate CSA row or a duplicate AWG row.
- Reject more than 60 rows.
- E4 refuses I_t outside 0.1 to 5000 A and CSA outside 0.1 to 1000 mm2.
- E4 refuses an AWG number outside -3 to 40.
- Warn when CSA and I_t do not both rise together.

## Maps to CalcDataRecord
Kind is `cable.ampacity`. The importer saves one CalcDataRecord for the file.
One CalcDataValue with Symbol `ampacity` holds Rows. Each CalcRow has one cell per column, keyed by column symbol.
