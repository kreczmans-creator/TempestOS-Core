# 13 ec3.partial-factors

Kind: `ec3-1-1.national-annex` (EN 1993-1-1 National Annex factor).
Status: existing CalcRecordKind `ec3-1-1.national-annex`
Planned name: `ec3.partial-factors`. The built calculator names the kind `ec3-1-1.national-annex`. The file name stays.

## Used by
- S6 base plate (built, `struct.base-plate`) reads `gamma_M0` for the plate and the bearing outstand.
- S3 member checks (built) lists no record kind. It takes its factors as typed inputs.
- S8 lifting lugs and S7 LTB (planned) will need gamma_M0 as well.

## Symbol mapping
- `gamma_M0[-]` fills the S6 input `gamma_M0`, a number.
- The planned columns `gamma_M1` and `gamma_M2` are gone. No built calculator reads them from this kind.
- S6 reads gamma_M2 from template 14, kind `ec3.national-annex`. Type gamma_M1 there when a calculator needs it.

## Copy from
- Type the value from the National Annex to BS EN 1993-1-1, the clause on partial factors for resistance.
- The Eurocode places the clause at 6.1(1). Confirm the National Annex clause number against your copy.

## Columns
- `gamma_M0[-]`: partial factor for cross-section resistance.

## Edition to record
Record the National Annex edition and amendment, and the edition of the Eurocode part it modifies.

## Importer checks
- Reject a blank or non-positive gamma_M0. Reject a gamma_M0 below 1.
- S6 refuses gamma_M0 outside 1.0 to 1.25.
- Reject a file with more than one data row.

## Maps to CalcDataRecord
Kind is `ec3-1-1.national-annex`. The importer saves one CalcDataRecord for the file.
The column becomes one CalcDataValue with Symbol `gamma_M0`, a Number and the Unit `-`.
