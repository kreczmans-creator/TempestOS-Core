# 39 en10270.spring-wire

Kind: `en10270.spring-wire` (EN 10270 spring wire tensile strength).
Status: proposed — no CalcRecordKind yet; Track S confirms symbols when the calculator is built

## Used by
- M7 springs (planned) reads the minimum tensile strength R_m for each wire diameter.

## Copy from
- Type the values from BS EN 10270-1 (patented cold-drawn wire) or the part for your wire.
- Cite the part, the edition, and the tensile strength table number.

## Columns
- `grade[text]`: wire grade, as the standard prints it.
- `d[mm]`: wire diameter.
- `R_m_min[MPa]`: minimum tensile strength.
- `R_m_max[MPa]`: maximum tensile strength.
- `G[GPa]`: shear modulus. Repeat on each row of the grade.
- `E[GPa]`: Young's modulus. Repeat on each row of the grade.

## Edition to record
Record the part number, edition and amendment of BS EN 10270.

## Importer checks
- Reject any row with a blank or non-positive number in a numeric column.
- Reject a row where R_m_max is below R_m_min.
- Within one grade, d must rise and R_m_min must not rise.
- Reject a duplicate grade and d row.
- Warn when R_m_min is outside 500 to 3000 MPa.

## Maps to CalcDataRecord
Kind is `en10270.spring-wire`. The importer saves one CalcDataRecord for the file.
One CalcDataValue with Symbol `wire_strength_table` holds Rows. Each CalcRow has one cell per column, keyed by column symbol.
