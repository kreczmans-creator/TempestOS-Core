# 03 bs7671.max-zs

Kind: `bs7671.max-zs` (BS 7671 maximum earth fault loop impedance).
Status: proposed — no CalcRecordKind yet; Track S confirms symbols when the calculator is built

## Used by
- E5 fault protection (built) can check its derived Z_s,max against the table.
- E4 conductor sizing (planned) will limit circuit length with it.

## Copy from
- Type the values from BS 7671:2018 (as amended), Tables 41.2, 41.3 and 41.4.
- Enter one table per file. Name the table in table_or_clause.

## Columns
- `device[text]`: device family as the table names it.
- `t_disc[s]`: disconnection time the table column states.
- `I_n[A]`: device rated current.
- `Z_s_max[ohm]`: maximum earth fault loop impedance.

## Edition to record
Record the amendment, because the tables change between amendments. State the conductor temperature the table assumes in notes.

## Importer checks
- Reject any row with a blank or non-positive number in a numeric column.
- Reject a duplicate device, t_disc and I_n row.
- Within one device and t_disc, Z_s_max must fall as I_n rises.
- Warn when Z_s_max is outside 0.01 to 3 ohm, the range of the E5 input Z_e.

## Maps to CalcDataRecord
Kind is `bs7671.max-zs`. The importer saves one CalcDataRecord for the file.
One CalcDataValue with Symbol `Z_s_max_table` holds Rows. Each CalcRow has one cell per column, keyed by column symbol.
