# 07 bs7671.factors-grouping

Kind: `cable.correction-factors` (ambient, grouping and thermal-insulation factors for one installation method).
Status: existing CalcRecordKind `cable.correction-factors`
Planned name: `bs7671.factors-grouping`. The built calculator names the kind `cable.correction-factors`. The file name stays.

## Used by
- E4 conductor sizing (built, `elec.conductor-sizing`) reads `C_g` into its grouping correction factor input.
- E4 does not look C_g up from the number of circuits. It warns when N_g is above 1 and C_g is 1.

## Symbol mapping
- `C_g[-]` is the only applied column. It fills the E4 input `C_g`, a number.
- `arrangement` and `n_circuits` identify the row. The importer stores them but E4 never reads them.
- The E4 input `N_g` is separate. Applying this record never sets it. Type the same count there.
- The importer saves one record per row. Pick the row for your arrangement and circuit count.
- Templates 06 and 08 fill the other two symbols of the same kind.

## Copy from
- Type the values from BS 7671:2018 (as amended), Appendix 4.
- Use the grouping factor tables, such as Tables 4C1 to 4C5.
- Enter one table per file. Confirm the table numbers against your copy.

## Columns
- `arrangement[text]`: arrangement as the table names it, such as bunched or single layer.
- `n_circuits[-]`: number of circuits or multicore cables in the group.
- `C_g[-]`: grouping correction factor.

## Edition to record
Record the BS 7671 edition and amendment printed on your copy. Use the edition and amendment fields.

## Importer checks
- Reject a blank or non-positive C_g. Reject a non-integer n_circuits.
- Reject a duplicate arrangement and n_circuits row.
- Within one arrangement, n_circuits must rise and C_g must not rise.
- Reject a C_g above 1. E4 refuses C_g outside 0.1 to 1.5.

## Maps to CalcDataRecord
Kind is `cable.correction-factors`. The importer saves one CalcDataRecord per CSV row.
The `C_g` column becomes one CalcDataValue with Symbol `C_g`, a Number and the Unit `-`.
The `arrangement` and `n_circuits` cells join the record title. The kind does not list them, so they are stored but never applied.
