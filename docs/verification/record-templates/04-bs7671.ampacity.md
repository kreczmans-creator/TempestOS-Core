# 04 bs7671.ampacity

Kind: `cable.ampacity` (cable current-carrying capacities for one installation method and insulation).
Status: existing CalcRecordKind `cable.ampacity`
Planned name: `bs7671.ampacity`. The built calculator names the kind `cable.ampacity`. The file name stays.

## Used by
- E4 conductor sizing (built, `elec.conductor-sizing`) reads this record into its `ampacity` table input.
- E3 voltage drop (built) takes the tabulated capacity as its optional I_z input. It does not read this record.
- Template 10 fills the same kind from the machine wiring standard.

## Symbol mapping
- The whole file becomes one value with Symbol `ampacity`. Its rows fill the `ampacity` table input.
- Each header is a column symbol of that table: `CSA` in mm^2, `AWG` with no unit, `I_t` in A.
- The importer writes `mm2` as mm^2. Track S confirms this.

## Copy from
- Type the values from BS 7671:2018 (as amended), Appendix 4.
- Use the current-carrying capacity tables, which carry an A suffix, such as Table 4D2A.
- Enter one table per file. One table means one installation method, one insulation and one loaded-conductor count.
- Name the method, insulation, conductor material and table in `table_or_clause` and `notes`.
- Give each file its own title label, such as `Title [method C]`.

## Columns
- `CSA[mm2]`: conductor cross-sectional area. Fill it for a metric table. Leave it blank for an AWG table.
- `AWG[-]`: AWG gauge number n. Fill it for an AWG table. Leave it blank for a metric table.
- `I_t[A]`: tabulated current-carrying capacity.

The old columns `conductor`, `method` and `loaded_conductors` are gone. E4 does not read them.

## Edition to record
Record the BS 7671 edition and amendment printed on your copy. Use the edition and amendment fields.

## Importer checks
- Reject a row with a blank or non-positive I_t.
- Reject a row that fills neither CSA nor AWG.
- Reject a duplicate CSA row or a duplicate AWG row.
- Reject more than 60 rows. E4 takes 60 rows at most.
- E4 refuses I_t outside 0.1 to 5000 A, CSA outside 0.1 to 1000 mm2 and AWG outside -3 to 40.
- Warn when CSA and I_t do not both rise together.

## Maps to CalcDataRecord
Kind is `cable.ampacity`. The importer saves one CalcDataRecord for the file.
One CalcDataValue with Symbol `ampacity` holds Rows. Each CalcRow has one cell per column, keyed by column symbol.
Applying the record to an E4 draft fills the `ampacity` input and pins the record as its source.
