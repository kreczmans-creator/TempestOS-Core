# 04 bs7671.ampacity

Kind: `bs7671.ampacity` (BS 7671 current-carrying capacity).
Status: proposed — no CalcRecordKind yet; Track S confirms symbols when the calculator is built

## Used by
- E4 conductor sizing (planned) reads I_t for each installation reference method.
- E3 voltage drop (built) takes the tabulated capacity as its optional I_z input.

## Copy from
- Type the values from BS 7671:2018 (as amended), Appendix 4.
- Use the current-carrying capacity tables, which carry an A suffix, such as Table 4D2A.
- Enter one table per file. Name the table in table_or_clause.

## Columns
- `conductor[text]`: copper or aluminium, as the table names it.
- `method[text]`: installation reference method letter, such as A, B, C, E, F or G.
- `loaded_conductors[-]`: number of loaded conductors the column states.
- `csa[mm2]`: conductor cross-sectional area.
- `I_t[A]`: tabulated current-carrying capacity.

## Edition to record
Record the BS 7671 edition and amendment printed on your copy. Use the edition and amendment fields.

## Importer checks
- Reject any row with a blank or non-positive number in a numeric column.
- Reject a duplicate conductor, method, loaded_conductors and csa row.
- Within one conductor, method and loaded_conductors, csa and I_t must both rise together.
- Warn when I_t is outside 1 to 5000 A.
- Warn when I_t for 3 loaded conductors exceeds the 2-conductor value at the same csa and method.

## Maps to CalcDataRecord
Kind is `bs7671.ampacity`. The importer saves one CalcDataRecord for the file.
One CalcDataValue with Symbol `I_t_table` holds Rows. Each CalcRow has one cell per column, keyed by column symbol.
