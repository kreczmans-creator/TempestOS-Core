# 11 en60204.factors

Kind: `cable.correction-factors` (ambient, grouping and thermal-insulation factors for one installation method).
Status: existing CalcRecordKind `cable.correction-factors`
Planned name: `en60204.factors`. The built calculator names the kind `cable.correction-factors`. The file name stays.

## Used by
- E4 conductor sizing (built, `elec.conductor-sizing`) reads `C_a` and `C_g` from this record.
- Set the E4 context to the machine wiring option when you apply it. The context changes the clause citations only.
- Templates 06 to 08 fill the same kind from BS 7671.

## Symbol mapping
- `C_a[-]` fills the E4 input `C_a`. Fill it on ambient rows only.
- `C_g[-]` fills the E4 input `C_g`. Fill it on grouping rows only.
- `factor`, `theta_a` and `n_circuits` identify the row. The importer stores them but E4 never reads them.
- The importer saves one record per row. A row with a blank factor value applies nothing for that symbol.
- The planned column `k_derate` is gone. It split into `C_a` and `C_g`.

## Copy from
- Type the values from BS EN 60204-1:2018, Annex D.
- Use the ambient temperature and grouping derating tables. Record the table numbers you use.

## Columns
- `factor[text]`: factor name as the table gives it, such as ambient or grouping.
- `theta_a[degC]`: ambient temperature. Fill on ambient rows only.
- `n_circuits[-]`: number of loaded circuits or cables. Fill on grouping rows only.
- `C_a[-]`: ambient derating factor. Fill on ambient rows only.
- `C_g[-]`: grouping derating factor. Fill on grouping rows only.

## Edition to record
Record the BS EN 60204-1 edition and any amendment or corrigendum.

## Importer checks
- Reject a row that fills both C_a and C_g, or neither.
- Reject a row that fills C_a without theta_a, or C_g without n_circuits.
- Reject a non-positive factor. E4 refuses a factor outside 0.1 to 1.5.
- Within one factor, the condition must rise and the factor must not rise, except below the reference ambient.
- Reject a duplicate factor and condition row.

## Maps to CalcDataRecord
Kind is `cable.correction-factors`. The importer saves one CalcDataRecord per CSV row.
The filled factor column becomes one CalcDataValue with Symbol `C_a` or `C_g`, a Number and the Unit `-`.
The `factor`, `theta_a` and `n_circuits` cells join the record title. The kind does not list them, so they are stored but never applied.
