# 09 bs7671.factors-protection

Kind: `bs7671.factors-protection` (BS 7671 semi-enclosed fuse factor Cc).
Status: proposed — no CalcRecordKind yet; Track S confirms symbols when the calculator is built

## Used by
- E4 conductor sizing (planned) applies C_c when a semi-enclosed fuse gives overload protection.

## Copy from
- Type the value from BS 7671:2018 (as amended), Appendix 4.
- Cite the paragraph that defines the factor. Skip this file if you never use semi-enclosed fuses.

## Columns
- `C_c[-]`: correction factor for protection by a semi-enclosed fuse.

## Edition to record
Record the BS 7671 edition and amendment printed on your copy. Use the edition and amendment fields.

## Importer checks
- Reject a blank or non-positive C_c. Reject a C_c above 1.
- Reject a file with more than one data row.

## Maps to CalcDataRecord
Kind is `bs7671.factors-protection`. The importer saves one CalcDataRecord for the file.
Each column becomes one CalcDataValue with its Symbol, Number and Unit.
