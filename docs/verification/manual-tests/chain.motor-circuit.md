# Manual test — chain.motor-circuit (Motor circuit: motor, load budget, cable, voltage drop, fault protection, enclosure heat)
Liability: High. Time: ~110 min. Pre-requisites: a project open in the desktop app. The JSON sets at the end of this file. A second user account for the independent check. A pocket calculator for the hand checks. Keep the same project open for the whole chain, because links only reach calculations in the open project.

Step 1 uses the Calculation packs panel. Steps 9 and 10 use the Saved calculations panel. Both sit in the left column of the Calculation worksheets view, under the catalogue. Open the view with Ctrl+K and `Open worksheet:` and any calculator name. To reopen a calculation, select its row in the Saved calculations list and press Open. If the status line says the form has unsaved changes, press Open a second time to discard them. A row ending with STALE has an upstream that moved.

The pack panel cannot build this chain, so steps 2 to 8 build it by hand. Each form opens on its first known-answer case, not on a clean sheet. So import the named set at every step. An import resets every input it does not list to the template default. To reset a form, copy `[]` and import it. The tables of E6 and E2 reset to empty only if the set lists them, as the sets here do. Import reads the clipboard: copy the JSON, then press "Import inputs (CSV/JSON)". Save with "Save as calculation". To link an input, use the Link panel below the inputs. Pick the input, the calculation and the output. Then press "Link input". A link is pinned to the revision it was made against. The results panel shows five significant figures. The pack `pack.motor-circuit` is defined in src/Tempest.Calc/Tempest.Calc.Library/CalcPackTemplates.cs. It has nine links. They are E1 P_pk to E6 P_add. Then E6 I_3ph to E4 I_b_in. Then E4 I_b to E3 I, E4 L to E3 L and E4 CSA to E3 A_c. Then E4 CSA to E5 S_line, E4 L to E5 L and E4 I_n to E5 I_n. Last, E6 Phi to E2 P_add. The sets give no source for the inputs. So the steps here do not press "Record check", except where a refusal is the aim.
