# Manual test — chain.drive-train (Drive train: motor, shaft, bearing life, seat fit, coupling flange bolts)
Liability: High. Time: ~110 min. Pre-requisites: a project open in the desktop app; the JSON sets at the end of this file for Part B and the finding steps. Keep the same project open for the whole chain, because links only reach calculations in the open project.

Steps 1 to 15 use the Calculation packs panel and the Saved calculations panel. Both sit in the left column of the Calculation worksheets view, under the catalogue. Open the view with Ctrl+K and `Open worksheet:` and any calculator name. The pack `pack.drive-train` is defined in src/Tempest.Calc/Tempest.Calc.Library/CalcPackTemplates.cs. It now has five steps and six links. They are E1 T_rms to M4 T; E1 n_pk to M4 n; M4 R_A to M5 F_r; E1 n_pk to M5 n; M4 d_A to M2 D; and E1 T_pk to M3 T_z. The pack starts from the example inputs in CalcPackExamples.cs: a 4-pole motor with a 12.5:1 gearbox that turns a conveyor drum at 120 rpm against 1.8 kN*m. Each example input carries the source assumption "example input — replace with your own". That source is enough to check and issue.

Steps 16 to 23 (Part B) build a ball-screw chain by hand. Import reads the clipboard: copy the JSON, then press Import inputs (CSV/JSON). Save with Save as calculation. To link an input, use the Link panel below the inputs: pick the input, the calculation and the output, then press Link input. A link is pinned to the revision it was made against. To reopen a calculation, select its row in the Saved calculations list and press Open. If the status line says the form has unsaved changes, press Open a second time to discard them. A row ending with STALE has an upstream that moved. The results panel shows five significant figures.
