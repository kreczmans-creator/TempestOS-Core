# Manual test — chain.drive-train (Drive train: motor, shaft, bearing life, seat fit)
Liability: High. Time: ~75 min. Pre-requisites: a project open in the desktop app; the JSON sets at the end of this file; about 20 minutes extra if you check and issue every sheet.

How to open each calculator: press Ctrl+K, type `Open worksheet:` and the calculator name, press Enter. Or use Engineering → Modules → Calculations → Worksheets. Import reads the clipboard: copy the JSON, then press "Import inputs (CSV/JSON)". Save with "Save as calculation". Reopen a saved calculation from Engineering → Modules → Calculations → Calculation register. To link an input, use the Link panel below the inputs. Pick the input, the calculation and the output. Then press "Link input". A link is pinned to the revision it was made against. The form shows a stale marker when an upstream calculation was revised or changed. The pack `pack.drive-train` is defined in src/Tempest.Calc/Tempest.Calc.Library/CalcPackTemplates.cs. Its links are E1 T_rms to M4 T; E1 n_pk to M4 n; M4 R_A to M5 F_r; E1 n_pk to M5 n; M4 d_A to M2 D.
