# Manual test — bs.room-heat-loss (U-values and room heat loss)
Liability: Medium. Time: ~60 min. Pre-requisites: a project open in the desktop app. The JSON sets at the end of this file. The Heat exchanger worksheet for step 16. A pocket calculator for the hand checks.

How to open: press Ctrl+K, type `Open worksheet: U-values and room heat loss`, press Enter. Or use Engineering → Modules → Calculations → Worksheets, then pick the calculator under Building Services. The form opens on the scalar values of the first known-answer case. The layers and elements tables open empty, because tables have no form fields. You enter them by import only. The results panel shows five significant figures. Press "Show working" to see each formula step. The unit picker offers only matching units. Import reads the clipboard: copy the JSON, then press "Import inputs (CSV/JSON)". The status line reads "Imported n input(s)". Every import resets each input it does not list to the template default, not to the first case. To return to the template defaults, copy `[]` and import it. Start each step from the import it names. The layer conductivities in the sets are illustrative test values, not design data. Warnings say that theta_e, the elements and the layers did not come from a reference record. That is expected.
