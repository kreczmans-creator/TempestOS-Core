# Manual test — bs.psychrometrics (Psychrometrics)
Liability: High. Time: ~40 min. Pre-requisites: a project open in the desktop app. No table inputs, so no JSON import is needed except for the unit-mismatch step.

How to open: press Ctrl+K, type `Open worksheet: Psychrometrics`, press Enter. Or use Engineering → Modules → Calculations → Worksheets, then pick the calculator under Building Services. The form recalculates at once. Results show five significant figures. "Show working" lists each formula step. The unit picker offers only matching units, so a wrong unit can only come in by import. Import reads the clipboard: copy the JSON, then press "Import inputs (CSV/JSON)". The form opens with the worked example of the first known-answer case, not the bare template defaults. To return to the template defaults, copy `[]` and press "Import inputs (CSV/JSON)". Start each step from a reset, so that values left from earlier steps cannot change the result. A step that says it continues from the last step is the exception.
