# Manual test — elec.fault-protection (Fault protection: Zs, disconnection, adiabatic, fault level)
Liability: High. Time: ~35 min. Pre-requisites: a project open in the desktop app; the fuse-curve JSON below ready to copy; a second user account for the independent check; a pocket calculator for the hand checks.

How to open: press Ctrl+K, type `Open worksheet: Fault protection`, press Enter. Or use Engineering → Modules → Calculations → Worksheets, then pick the calculator under Electrical. The form opens with the first known-answer case, which here equals the template defaults. The results panel shows five significant figures. Press "Show working" to see each formula step. The unit picker offers only matching units, so a wrong unit can only come in by import. Import reads the clipboard: copy the JSON, then press "Import inputs (CSV/JSON)". To return to the template defaults, copy `[]` and import it. Start each step from a reset, so that values left from earlier steps cannot change the result. A step that says it continues from the last step is the exception.
