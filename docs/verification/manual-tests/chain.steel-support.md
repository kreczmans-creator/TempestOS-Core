# Manual test — chain.steel-support (Steel support: load combinations, frame, column, arm joint, base plate)
Liability: High. Time: ~90 min. Pre-requisites: a project open in the desktop app. A second person in the People directory for the independent check (Settings, Switch person…). A small PDF to file as a placeholder. A pocket calculator for the hand checks. Keep the same project open for the whole chain, because links only reach calculations in the open project.

All steps use the Calculation packs panel and the Saved calculations panel. Both sit in the left column of the Calculation worksheets view, under the catalogue. Open the view with Ctrl+K and `Open worksheet:` and any calculator name. To reopen a calculation, select its row in a list. Use the Saved calculations list or the member list of the pack. Press Open or Open pack member. If the status line says the form has unsaved changes, press Open a second time to discard them. A row ending with STALE has an upstream that moved. The results panel shows five significant figures.

The pack `pack.steel-support` is new in this release. It is defined in src/Tempest.Calc/Tempest.Calc.Library/CalcPackTemplates.cs. It has seventeen links. S5 E_d_min fills row 1 of the S2 load table (a table-cell link). S2 N_e1, M_abs_e1 and V_e1 feed S3. S2 V_e2 and M_abs_e2 load the arm joint bolt group (M3). Its v_max and t_max feed the arm connection (S4a), together with S2 V_e2. S2 R1_y, R1_m_abs and R1_x_abs are the base plate actions. The holding-down bolts (S4b) give S6 five values. The pack starts from the example inputs in CalcPackExamples.cs: an equipment bracket on a cantilever column. Every example input carries the source assumption "example input — replace with your own". That source is enough to check and issue. No step needs a JSON set.
