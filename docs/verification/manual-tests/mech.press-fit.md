## Import blocks
Copy the whole line of a block to the clipboard. Then press *Import inputs (CSV/JSON)*. The status line must read "Imported n input(s)".

**Block N** — Interface diameter entered in newtons.
```json
[{"Symbol":"d","Number":50,"Unit":"N"}]
```

## Notes for the tester
- Hub von Mises is checked at the bore. Shaft von Mises is checked at the outer surface only. See step 11.
