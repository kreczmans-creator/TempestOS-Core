# Manual test — elec.conductor-sizing (Conductor sizing and overload coordination)
Liability: High. Time: ~60 min. Pre-requisites: a project open in the desktop app. The JSON sets at the end of this file, ready to copy. A second user account for the independent check. A pocket calculator for the hand checks.

How to open: press Ctrl+K, type `Open worksheet: Conductor sizing`, press Enter. Or use Engineering → Modules → Calculations → Worksheets, then pick the calculator under Electrical. The form opens on the first known-answer case. Its scalar values are T_amb 35 degC, two grouped circuits, C_a 0.91 and C_g 0.77. The two tables, ratings and ampacity, open empty on purpose. You enter them from your own source. The sets below hold synthetic test values from the calculator's own known-answer cases, not table values. Import reads the clipboard: copy the JSON, then press "Import inputs (CSV/JSON)". The status line reads "Imported n input(s)". Every import resets each input it does not list to the template default, not to the first case. To return to the template defaults, copy `[]` and import it. Start each step from the import it names. The results panel shows five significant figures. Press "Show working" to see each formula step. The unit picker offers only matching units. Each run raises four warnings that a table value did not come from a reference record. That is expected.
