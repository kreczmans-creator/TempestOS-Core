# Manual test — chain.wet-heating (Wet heating: room heat loss, sealed system, pipework and pump, circulator motor)
Liability: High. Time: ~100 min. Pre-requisites: a project open in the desktop app. The JSON sets at the end of this file for the finding steps. A pocket calculator for the hand checks. Keep the same project open for the whole chain, because links only reach calculations in the open project.

Steps 1 to 12 use the Calculation packs panel and the Saved calculations panel. Both sit in the left column of the Calculation worksheets view, under the catalogue. Open the view with Ctrl+K and `Open worksheet:` and any calculator name. To reopen a calculation, select its row in a list. Use the Saved calculations list or the member list of the pack. Press Open or Open pack member. If the status line says the form has unsaved changes, press Open a second time to discard them. A row ending with STALE has an upstream that moved. The results panel shows five significant figures.

The pack `pack.wet-heating` is defined in src/Tempest.Calc/Tempest.Calc.Library/CalcPackTemplates.cs. It has seven links. B4 room A Φ_HL fills row 1 of the B6 table `rooms`, column Phi. B4 room B Φ_HL fills row 2. These two are table-cell links. Then B6 Phi_tot goes to B1 Phi_load, B6 dT_fr to B1 dT_load and B6 t_m to B1 T. Last, B1 T_shaft goes to E1 T_L and B1 n_shaft to E1 n_L. The pack starts from the example inputs in CalcPackExamples.cs. Every example input carries the source assumption "example input — replace with your own". That source is enough to check and issue. The finding steps from 13 use their own JSON sets on separate sheets. Import a set with Import inputs (CSV/JSON). An import resets every input it does not list to the template default.
