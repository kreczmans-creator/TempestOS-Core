# Manual test — chain.wet-heating (Wet heating: room heat loss, sealed system, pipework and pump, circulator motor)
Liability: High. Time: ~100 min. Pre-requisites: a project open in the desktop app. The JSON sets at the end of this file. A pocket calculator for the hand checks. Keep the same project open for the whole chain, because links only reach calculations in the open project.

How to open each calculator: press Ctrl+K, type `Open worksheet:` and the calculator name, press Enter. Or use Engineering → Modules → Calculations → Worksheets. Each form opens on its first known-answer case, not on a clean sheet. So import the named set at every step. An import resets every input it does not list to the template default. To reset a form, copy `[]` and import it. Import reads the clipboard: copy the JSON, then press "Import inputs (CSV/JSON)". Save with "Save as calculation". To link an input, use the Link panel below the inputs. Pick the input, the calculation and the output. Then press "Link input". A link is pinned to the revision it was made against. The form shows a stale marker when an upstream calculation was revised. The results panel shows five significant figures.

The pack `pack.wet-heating` is defined in src/Tempest.Calc/Tempest.Calc.Library/CalcPackTemplates.cs. It has seven links. B4 room A Φ_HL fills row 1 of the B6 table `rooms`, column Phi. B4 room B Φ_HL fills row 2. These two are table-cell links. Then B6 Phi_tot goes to B1 Phi_load, B6 dT_fr to B1 dT_load and B6 t_m to B1 T. Last, B1 T_shaft goes to E1 T_L and B1 n_shaft to E1 n_L. E1 runs in continuous duty. The Link panel lists only number and quantity inputs, so it cannot link a table cell. Step 4 therefore types the loads of room A and room B into B6 by hand. The sets give no source for the inputs. So the steps here do not press "Record check".
