| D-01 | 2026-10-23 | **Engine: own implementation, not CalcpadCE.** `Tempest.Calc.Engine` is a hand-written expression parser and evaluator over a runtime SI dimension vector, with structured step recording. CalcpadCE (`imartincei/CalcpadCE` @ `5cc3734`, MIT) is not vendored. | Spike evidence: `Calcpad.Core` is 43,965 lines in 93 files (MathParser 12,136; Matrix 12,240); it takes `SkiaSharp`, `Markdig.Signed`, `System.IO.Packaging` and `Calcpad.OpenXml`; its result of a run is rendered HTML/text (`OutputWriter`), not a structured step record, so a formula→substitution→result log would need invasive edits to a 12k-line parser; its own language has loops/macros that would need capping under security review. Cleanly isolating the evaluator+units within the 8 h box was judged not achievable; a ~3k-line engine under full control is. UnitsNet was also not taken: it is a typed-quantity library, and an expression engine needs runtime dimension algebra (`m^4/m^2`, `sqrt(I/A)`), which a 7-exponent dimension vector gives in ~300 lines with no dependency. |
