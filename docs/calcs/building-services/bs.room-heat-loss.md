# B4 — U-values and room heat loss (`bs.room-heat-loss@1.0.0`)

**Scope.** One room per sheet: the U-value of each built-up element from its layers and surface resistances, and the steady-state design heat loss of the room (fabric through each element to its adjacent temperature, a thermal-bridge allowance, ventilation through the outside air or an MVHR supply), the heat loss coefficient, and an optional check of each element against a target U.

**Method.** `U = 1/(R_si + Σ d/λ + R_g + R_se)` for homogeneous layers in series (BS EN ISO 6946), or the user's U override for ground floors and glazing. `Φ_i = A·U·f·(θ_int − θ_adj)`, with `θ_adj = θ_e` where the element faces outside. `Φ_tb = y_tb·ΣA_ext·(θ_int − θ_e)` on the elements facing outside (those with no adjacent temperature). `Φ_T = ΣΦ_i + Φ_tb`. `q_v = n·V`; `Φ_V = 0.34·q_v·(θ_int − θ_e)`, or `(θ_int − θ_supply)` when an MVHR supply temperature is entered (BS EN 12831-1 cl. 6.3.3). `Φ_HL = Φ_T + Φ_V`; `HLC = Φ_HL/(θ_int − θ_e)`; `Φ_A = Φ_HL/A_floor`. The 0.34 Wh/(m³·K) is the conventional rounded ρ·c_p of air (derived: about 1.2 kg/m³ × 1005 J/(kg·K) ÷ 3600). The method selector changes the citations; the CIBSE DHDG option also applies the user's additional allowance, `Φ_HL = (Φ_T + Φ_V)(1 + f_add)` (ignored, with a warning, for BS EN 12831-1). The U arithmetic is the series-resistance sum of the legacy module `calc.plane-wall-heat-transfer` (films 1/R_si and 1/R_se); an agreement test in the Library test project runs both on the same walls to 1e-9.

**Inputs.**
- `method` ("BS EN 12831-1 elemental" or "CIBSE DHDG reduced method"); `theta_int` 16–24 °C; `theta_e` −15 to +5 °C (record `climate.design-temperature`).
- `layers` table (≤ 200 rows): element, layer name, `d` 1–500 mm, `λ` 0.01–5 W/(m·K) (record `material.conductivity`). Several elements share the table, keyed by the element name, or by the `construction` cell of the elements table where two elements share one build-up.
- `elements` table (≤ 60 rows, unique names): area 0.1–500 m²; optional adjacent temperature (blank = outside); optional `f` (blank = 1); optional `Rsi`, `Rse`, `Rg` (record `surface.resistances`); optional U override (ground floor, glazing); optional per-element target U; optional `construction`.
- `y_tb` W/(m²·K), default 0 (record `thermal.bridging`); optional `U_target` for built-up elements that have no target of their own.
- `n` 0.1–3 h⁻¹; `V` m³; optional `theta_supply` (MVHR); optional `A_floor`; `f_add` 0–50 % (DHDG only).
- Blank `Rsi` is the BS EN ISO 6946 conventional horizontal-flow 0.13 m²K/W; blank `Rse` is 0.04 outside or 0.13 for an element facing a heated space. These are the only surface-resistance values in the product, are listed on the sheet's assumptions, and are for walls; floors and roofs take the user's values. No conductivity, design temperature or CIBSE/MCS table ships.

**Outputs.** Per element `R_i`, `U_i`, `Phi_i` (and `u_i` against a target); `A_fab`, `A_ext`, `U_m`, `dT`, `Phi_el`, `Phi_tb`, `Phi_T`, `q_v`, `Phi_V`, `Phi_HL`, `HLC`, `Phi_A`. **Ports.** `Phi_HL` (→ B6 room heat required), `HLC`, `Phi_T`, `Phi_V`. **Checks.** One utilisation check per element with a target (U/U_target ≤ 1).

**Limitations.** Steady state, no gains, no thermal mass or dynamic simulation. Homogeneous layers only: no bridged-layer (combined) method, no corrections for fixings, ventilated cavities or inverted roofs. Ground-floor U is user-entered; there is no ground model. The thermal-bridge allowance is a single W/(m²·K) on the area facing outside (a deliberate reading of "total fabric area": partitions to heated spaces carry no bridges). No intermittency or reheat allowance except the DHDG user allowance.

**Test cases.** `ka-cavity-wall` (R 5.538045 m²K/W, U 0.180569, Φ_T 187.473 W, Φ_V 163.2 W, Φ_HL 350.673 W, HLC 14.6114 W/K), `ka-mvhr-partition` (partition U 1.851852, Φ_T 197.672 W, MVHR Φ_V 51 W, Φ_HL 248.672 W), `ka-dhdg-allowance` (Φ_HL × 1.10 = 385.741 W), `ka-single-layer-target` (U 2.702703, utilisation 0.9009) — analytic, Confirmed, recomputed independently. The conductivities in the cases are illustrative inputs, not design data. The CIBSE *Domestic Heating Design Guide* (2026 ed.) worked examples and the CIBSE Guide A (8th ed.) Ch. 3 U-value examples are **not pinned**: they need the owner's copies, and no example is entered from memory. Worked example: `semi-detached-living-room` (Φ_HL 611.78 W, 37.8 W/m²).
