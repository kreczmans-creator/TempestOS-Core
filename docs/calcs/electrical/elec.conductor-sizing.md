# E4 — Conductor sizing and overload coordination (`elec.conductor-sizing@1.0.0`)

**Scope.** One circuit: the design current, the smallest preferred device rating that carries it, the smallest conductor whose tabulated capacity (the user's own record) carries that rating once the correction factors are applied, and the overload coordination checks. The context choice (BS EN 60204-1 machine wiring, the default, or BS 7671 installation) changes the clause citations and the scope note only, never a number. **Independent check demanded** (DA-12); every numeric input outside its range is a hard FAIL (hard limit = stated range). Ships with E5 (`elec.fault-protection`).

**Method.**

- `I_b = P/(√3·U·cosφ·η)` three-phase, `P/(U·cosφ·η)` single-phase, `P/U` DC (power factor and efficiency not applied); or the linked `I_b_in`, which replaces the computed value.
- `I_n` = smallest rating in the `ratings` record with `I_n ≥ I_b`.
- `C_c = 0.725` for a semi-enclosed fuse only (1.45 divided by an assumed fusing factor of 2, derived), else 1.
- `I_t,req = I_n/(C_a·C_g·C_i·C_c)`. `C_a` is entered, or with `derive_Ca` derived as `√[(θ_p − θ_a)/(θ_p − θ_ref)]`, labelled "derived approximation — compare with the licensed table" (θ_p 70 °C for PVC, 90 °C for XLPE, the entered `theta_p` for "user"; θ_ref default 30 °C).
- `CSA` = smallest cross-section in the `ampacity` record with `I_t ≥ I_t,req` (row order does not matter). With the AWG system the row carries the gauge n and the area is the derived geometry `d = 0.127·92^((36 − n)/39) mm`, `A = π d²/4`; no AWG capacity is supplied.
- `I_z = I_t·C_a·C_g·C_i` (the factors actually applied; C_c is not part of it).
- Checks (BS 7671 reg. 433.1.1; BS EN 60204-1 cl. 12.4 and 7.2 in the machine context): `I_b ≤ I_n`, `I_n ≤ I_z`, `I₂ ≤ 1.45·I_z`, with `I₂ = 1.45·I_n` inherent for MCB types B, C, D and gG fuses, otherwise the `I2` input (without it a warning is raised and the check is skipped).

**Inputs.** `context`, `supply`, `P` 0.01–500 kW, `U` 12–1000 V, `cos_phi` 0.5–1, `eta` 0.5–1, optional `I_b_in` (A); `L` 0.1–500 m, `theta_a` −10 to 70 °C, `insulation` (PVC 70 °C / XLPE 90 °C / user), optional `theta_p` 50–250 °C, optional `method` (descriptive key such as B2, C, E), `N_g` 1–20 grouped circuits, `system` (metric / AWG); `device` (MCB type B, C, D, gG fuse, semi-enclosed fuse, MCCB, MPCB), optional `I2`; `C_a`, `C_g`, `C_i` 0.1–1.5 (default 1; record kind `cable.correction-factors`), `derive_Ca`, `theta_ref`; tables `ratings` (`I_n`; record kind `device.ratings`) and `ampacity` (`CSA` mm² or `AWG` gauge, and `I_t` A; record kind `cable.ampacity`). **No ampacity, rating or correction-factor value ships**: the tables are empty until the user enters them from their own licensed copy. `N_g` is carried to the sheet; `C_g` is not looked up from it, and `C_g = 1` with more than one circuit raises a warning.

**Outputs.** `I_b`, `I_n`, `C_c`, `C_a`, `I_t_req`, `CSA`, `I_z`, `L`, `u_Ib = I_b/I_n`, `u_In = I_n/I_z`, `I2`, `u_I2 = I₂/(1.45 I_z)`, and `gauge` (AWG system). **Ports.** `I_b` (A), `I_n` (A), `CSA` (mm²), `I_z` (A), `L` (m) → E3 (CSA, length), E5 (CSA, device), E2. **Checks.** `I_b ≤ I_n`, `I_n ≤ I_z`, `I₂ ≤ 1.45 I_z`, each PASS/FAIL with its utilisation. **Blocks** (each starts with the symbol and a colon): `ampacity:` empty table (enter your own licensed capacities, record kind `cable.ampacity`); `ratings:` empty table; `I_n:` no rating of at least `I_b`; `CSA:` no conductor carries `I_t,req`; `theta_p:`, `theta_a:` or `C_a:` when a derived factor cannot be formed.

**Limitations.** Single circuit, one installation method per run; the factors are applied as a product and are the user's; the derived `C_a` is a temperature-difference approximation only; the I²t/short-circuit and voltage-drop checks are E5 and E3; no cable ampacity, rating factor or standard table is embedded (§A5).

**Test cases.** All analytic and Confirmed, using illustrative test values (capacities 1.5→15, 2.5→21, 4→28, 6→36, 10→50 A; ratings 6, 10, 16, 20, 25, 32, 40, 50, 63 A) that are not from any standard, recomputed in Python: `ka-three-phase-mcb-c` (I_b 14.1507 A, I_n 16 A, I_t,req 21.2766 A, 4 mm², I_z 21.056 A), `ka-single-phase` (I_b 15.2555 A, 2.5 mm², I_z 21 A), `ka-dc` (I_b 25 A, I_t,req 27.7778 A, 4 mm², I_z 25.2 A), `ka-semi-enclosed` (C_c 0.725, I_t,req 27.5862 A, 4 mm²), `ka-derived-ca` (C_a = √(30/40) = 0.866025), `ka-awg-10` (AWG 10 = 5.2612 mm²). Not pinned — owner check: the Schneider *Electrical Installation Guide* chapter G worked examples, the IET *Electrical Installation Design Guide* examples and the Kollmorgen current-carrying-capacity note; no value from them is in source, tests or docs. The worked example `conveyor-motor-circuit` (4 kW, type C MCB, machine panel) uses the same illustrative tables, entered with record-style provenance.
