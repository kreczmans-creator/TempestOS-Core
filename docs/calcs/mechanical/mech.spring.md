# M7 — Helical springs: compression, extension, torsion (`mech.spring@1.0.0`)

**Scope.** Cylindrical helical springs of round wire, cold-coiled (d up to 20 mm), linear characteristic. Compression is the first mode: rate, working points (given as loads or as deflections), shear stress with a correction factor at the two working points and at solid length, solid length and pitch by end type, buckling, Goodman fatigue, surge frequency. Extension adds the initial tension and the two hook stresses. Torsion gives the rate with the legs, the curvature-corrected bending stress, the wound diameter and the body length. EN 13906-1/-2/-3 are cited by part and title only; their text, wire-strength tables and permissible-stress diagrams are not reproduced or shipped (Addendum B §B5).

**Method.**
- Index and rate: `C = D/d`; `k = G d⁴/(8 D³ n)` (compression, extension); torsion `k_φ = E d⁴/(64 D n_a)`, `n_a = n + (l₁ + l₂)/(3π D)`.
- Shear stress: `τ = k_c·8 F D/(π d³)`, `k_c` by choice: Bergsträsser `(C + 0.5)/(C − 0.75)` (the default; this is the form the spec brief calls the Wahl option, and the one printed as K_B in Shigley), Wahl `(4C − 1)/(4C − 4) + 0.615/C`, or none (uncorrected). The same factor is applied to the stress at solid, which is conservative for the static check.
- Solid length by end type (derived from the geometry of the end, Shigley 10th ed. Table 10-1 relations): `n_t = n + e_n`, `L_s = d (n_t + e_s)` with `(e_n, e_s)` = (0, 1) plain, (1, 0) plain and ground, (2, 1) squared (closed), (2, 0) squared and ground; pitch `p = (L₀ − a d)/(n + b)` with `(a, b)` = (1, 0), (0, 1), (3, 0), (2, 0). Travel to solid `s_c = L₀ − L_s`, `F_c = k s_c`.
- Extension: `F = F₀ + k s`; body length `d (n + 1)`; hook bending `σ_A = F [K_A·16 D/(π d³) + 4/(π d²)]`, `K_A = (4C₁² − C₁ − 1)/(4 C₁ (C₁ − 1))`, `C₁ = 2 r₁/d`; side-bend torsion `τ_B = K_B·8 F D/(π d³)`, `K_B = (4C₂ − 1)/(4C₂ − 4)`, `C₂ = 2 r₂/d`.
- Torsion: `K_i = (4C² − C − 1)/(4C (C − 1))`, `σ = K_i·32 M/(π d³)`; wound to angle φ the wire length is constant, so `D_w = D n/(n + φ/2π)` and the closed body is `d (n + 1 + φ/2π)` long.
- Buckling (compression): `λ_eff = ν L₀/D`; `y_cr = L₀ C₁′ [1 − √(1 − C₂′/λ_eff²)]`, `C₁′ = E/(2(E − G))`, `C₂′ = 2π²(E − G)/(2G + E)`; when `λ_eff² < C₂′` the spring is stable at any deflection. PASS when `s₂ < y_cr`, otherwise WARN (rule `buckling`).
- Fatigue (Goodman, the same relation as M4 `mech.shaft`: `1/n_f = a/S_e + m/S_u`; shared function `FatigueRelations.GoodmanUtilisation`, M4 itself unchanged): `a`, `m` from the stresses at working points 1 and 2; `S_u = f_su·R_m` in shear (compression, extension body), `R_m` in bending (torsion). Checked as `n_f,req·(1/n_f) ≤ 1`. Skipped with a warning (`fatigue-skipped`) when no `S_e` is entered; warning `fatigue-cycles` when `N_c < 10⁴`.
- Surge: `f_n = (d/(2π n D²))√(G/(2ρ))`, both ends fixed (the same as `½√(k/m)` with the wire mass). With an operating frequency `f_op`, `r_f = f_n/f_op`, WARN (rule `surge`) when `r_f < 13`.

**Inputs.** `mode`, `corr`, `d` 0.1–20 mm (hard 0.05–50), `D`, `n` (≥ 2 usual; torsion: body turns), `ends`, `L0`; hooks `r_h1`, `r_h2`; torsion legs `l_1`, `l_2`; working points by `work` (loads `F_1`, `F_2` / torques `M_1`, `M_2`, or deflections `s_1`, `s_2` / angles `phi_1`, `phi_2`) and `F_0` (extension). Material `G`, `E`, `rho` (W3 `MaterialProperty`; record kind `material.properties`). User inputs with records: `Rm` = R_m(d) (`spring.wire-strength`), `f_tau`, `f_sigma`, `f_su` (`spring.permissible`), `nu_seat` = ν, the end-support coefficient (`spring.seating`; 0.5 both ends fixed and parallel, 0.7 one fixed one pinned, 1 both pinned, 2 one end free), `S_e` (`spring.endurance`), `N_c`, `n_f_req`, `f_op`. Inputs a mode does not use are optional; one the chosen mode needs and that is blank blocks with a message naming it (`missing`). The defaults on a new sheet are example values; none is a published figure.

**Outputs.** Compression: `C`, `k`, `k_c`, `n_t`, `L_s`, `p`, `F_1`, `F_2`, `s_1`, `s_2`, `L_1`, `L_2`, `s_c`, `F_c`, `tau_1`, `tau_2`, `tau_c`, `u_2`, `u_c`, `y_cr`, `u_b`, `buckling` (PASS/WARN), `f_n`, `r_f`, `u_f`, `n_f`. Extension: the rate and working points, `tau_0`, `tau_1`, `tau_2`, `u_2`, `K_A`, `K_B`, `sigma_A`, `tau_B`, `u_A`, `u_B`, `f_n`, `r_f`, `u_f`, `n_f`. Torsion: `n_a`, `k_phi`, `K_i`, `phi_1`, `phi_2`, `M_1`, `M_2`, `sigma_1`, `sigma_2`, `u_2`, `D_w`, `L_w`, `u_f`, `n_f`. **Checks.** compression: static stress at solid length, travel to solid, Goodman; extension: body stress, hook bending, hook torsion, Goodman; torsion: bending stress, Goodman.

**Ports.** `k` N/mm (`spring.rate`), `F_1`, `F_2` N (`spring.force_at`), `L_s` mm (`spring.solid_length`: solid length in compression, closed body length in extension and torsion), `f_n` Hz (`spring.surge_freq`). The torsion rate is `k_phi` (N·m/rad, a different dimension) and is not a port. Links onward: M9 (follower force and rate), M4, M1.

**Limitations.** Linear characteristic; cold-coiled round wire up to 20 mm; no conical or variable-pitch springs, no rectangular wire; wire-diameter tolerance is not added to the solid length; extension hook fatigue and hook shape beyond the two radii are not assessed; surge for both ends fixed only; R_m(d), permissible stress fractions and endurance strength are the user's (no EN 10270 table, no EN 13906 permissible-stress diagram); the fatigue check is a Goodman line on the user's endurance strength, not a diagram.

**Test cases.** All four are analytic and Confirmed, recomputed in python3: `ka-compression` (k = 4.8828125 N/mm exactly, L_s 20 mm, s₂ 8.192 mm, τ₂ 238.842 MPa, τ_c 728.888 MPa, f_n 350.845 Hz, 1/n_f 0.347693), `ka-wahl-slender` (Wahl k_c 1.144833, y_cr 15.7950 mm, s₂/y_cr 0.759734, f_n 179.633 Hz), `ka-extension` (k = 1.953125 N/mm exactly, σ_A 693.006 MPa, τ_B 381.972 MPa, f_n 140.338 Hz), `ka-torsion` (k_φ 0.503096 N·m/rad, σ₂ 210.596 MPa, D_w 15.8745 mm). **Not pinned (owner check):** the Shigley 10th ed. solutions-manual values for problems 10-3 (k 1.314 N/mm, K_B 1.117, F_s 167.9 N, L₀ 162.8 mm), 10-5 (k 28 lbf/in, τ_s 48.56 kpsi) and 10-6 (k 3.333 N/mm, τ_s 178.2 MPa): the problem statements are not available to the build, so their inputs cannot be stated; add them as Unconfirmed + Secondary cases once the owner has the problem text. The EN 13906 clause numbers are not quoted (only part and title) for the same reason.
