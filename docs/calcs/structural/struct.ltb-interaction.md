# S7 — EN 1993-1-1 lateral-torsional buckling and N+M interaction (`struct.ltb-interaction@1.1.3`)

**In plain terms.** A long slender I-beam loaded in bending can twist and buckle sideways well before the steel yields, and a column can bow before it crushes; with both loads together the two effects add. The worksheet finds the moment at which the member would buckle elastically, reduces the plain strength by how close the member is to that moment, and checks the axial force and the bending moments together against the Eurocode 3 interaction rules.

**Scope.** A uniform, doubly-symmetric I-section member of class 1, 2 or 3 on fork supports (free to rotate about the minor axis and to warp at the ends, restrained against twist): the elastic critical moment, lateral-torsional buckling resistance (6.3.2.2 general case or 6.3.2.3 rolled and welded equivalent sections), flexural buckling about both axes (6.3.1) and the interaction of axial compression with bending about both axes (6.3.3, Annex B or Annex A). **Every numeric input has a hard range** (soft = hard): an input outside it blocks the sheet. Class 4 blocks.

**Limitations (also on the sheet).** Doubly-symmetric uniform members, fork supports; no mono-symmetric or tapered members, no cantilevers, no intermediate restraint, no cross-section classification or class 4 effective properties, no shear or cross-section (6.2.9) check; one moment diagram about y-y (linear, or `C_1`, `k_c`, `C_m` entered for others). `k` and `k_w` below 1 model partial end restraint; the ψ formula for `C_1` is for end moments with `k = 1`.

**Editions.** `edition` = `2005+A1:2014` (default, in force until the 2022 edition is adopted) or `2022`. **The 2022 choice changes the label only, by decision** (it is not an edition switch): the arithmetic implemented is that of 2005+A1:2014 (the differences between the editions are not implemented because they cannot be stated with certainty), clause numbers shown are the 2005 ones, and a warning says so.

**Method.** Formulas in own notation (see the template method text). `M_cr` by the general (NCCI SN003) expression with `C_1`, `C_2`, `k`, `k_w`, `z_g` (for a doubly-symmetric section; `z_g` positive for a load on the compression-flange side of the shear centre, which destabilises; `z_g` negative raises `M_cr`). `C_1 = 1.88 − 1.40ψ + 0.52ψ² ≤ 2.70` for end moments (derived curve fit, labelled) unless `C_1` is entered; for ψ < 0.25 the fit can exceed the exact elastic C₁ by up to about 10 % (long members, double curvature) and the sheet warns (`c1-psi`: check with an elastic buckling program and enter C₁); no table of `C_1` or `C_2` is shipped. `λ̄_LT = √(W_y f_y/M_cr)`, `W_y = W_pl,y` (class 1–2) or `W_el,y` (class 3). `χ_LT` by 6.3.2.2 (`Φ_LT = 0.5[1 + α_LT(λ̄_LT − 0.2) + λ̄_LT²]`, `χ_LT = 1/(Φ_LT + √(Φ_LT² − λ̄_LT²)) ≤ 1`) or 6.3.2.3 (`λ̄_LT,0`, `β`, `χ_LT ≤ 1/λ̄_LT²`); curve `auto` selects from the section type and h/b (Table 6.4 for 6.3.2.2, Table 6.5 for 6.3.2.3) or the curve is chosen. Optional `f` modification `χ_LT,mod = χ_LT/f`, not above 1 and not above `1/λ̄_LT²` (eq. 6.58), `f = 1 − 0.5(1 − k_c)[1 − 2(λ̄_LT − 0.8)²] ≤ 1` (6.3.2.3 only), `k_c` entered or `1/(1.33 − 0.33ψ)` for a linear diagram (**with `C_1` entered the sheet blocks until `k_c` is entered**, unless the diagram is given as end moments). `M_b,Rd = χ_LT W_y f_y/γ_M1`. Flexural buckling: `N_cr = π²EI/L_cr²`, `λ̄`, `χ` by the curve of each axis (`auto`, the default: Table 6.2 for S 235 to S 420 from the section type, `h/b` and the flange thickness `t_f` — rolled I, `h/b` > 1.2: a, b up to 40 mm and b, c up to 100 mm; `h/b` ≤ 1.2: b, c up to 100 mm and d, d beyond; welded I: b, c up to 40 mm and c, d above — or chosen by hand; for `f_y` above 420 MPa and the one combination without a row the curve must be chosen), `N_b,Rd = χ A f_y/γ_M1`. Interaction 6.61 and 6.62 with `k_yy, k_yz, k_zy, k_zz` from **Annex B** (Table B.1, or Table B.2 when the member is susceptible to torsional deformation; plastic for class 1–2, elastic for class 3; `C_m = 0.6 + 0.4ψ ≥ 0.4` for a linear diagram or entered — with `C_1` entered `C_my` must be entered, unless the diagram is given as end moments) or from **Annex A** (Table A.1 plastic column for class 1–2, elastic column for class 3 — without the 0.6√(w_i/w_j) factors of `k_yz` and `k_zy`; μ, w, n_pl, a_LT, `C_ij`, `C_my`, `C_mz`, `C_mLT`; `N_cr,T` with `l_T = k_w L`; N must stay below the elastic buckling forces; the LTB terms `b_LT … e_LT` are zero when `λ̄_0 ≤ 0.2√C_1⁴√((1 − N/N_cr,z)(1 − N/N_cr,T))`). The Annex A and Annex B expressions are implemented from the published formulae; **their coefficients are to be checked against the owner's copy of the standard** (the Annex A sheet carries a warning to that effect).

**Inputs.** Method `edition`, `ltb_method`, `annex`, `torsion`; material `f_y` 235–460 MPa, `E` 190–220 GPa, `G` 70–90 GPa (each takes a W3 material through the record kind `material.properties` and stays editable), `gamma_M1` 1.0–1.25 (record `ec3.national-annex`); section `section_class`, `section_type`, `h`, `b`, `t_f` (S1: `t_f`; selects the flexural curves), `A`, `I_y`, `I_z`, `I_t`, `I_w`, `W_pl_y`, `W_el_y`, `W_pl_z`, `W_el_z` (typed, or linked from an S1 sheet: S1's `I_xx`, `I_yy`, `J`, `I_w`, `W_pl_x`, `W_el_x`, `W_pl_y`, `W_el_y` map to `I_y`, `I_z`, `I_t`, `I_w`, `W_pl_y`, `W_el_y`, `W_pl_z`, `W_el_z`; no section tables are shipped); restraint `L` 0.1–100 m, `k` and `k_w` 0.5–1.0, `z_g` ±1000 mm, optional `C_1` 1–4, `C_2` 0–1.5, `ltb_curve`, `use_f`, optional `k_c` (record `ec3.mcr-factors`); factor set `alpha_a0 … alpha_d`, `lambda_LT0`, `beta_LT` (record `ec3.ltb-factors`, recommended values as defaults, labelled); actions `moment_mode` (`ψ and M_y,Ed` or `end moments` with signed `M_y_A`, `M_y_B`: **bending-moment-diagram ordinates, the same sign at both ends for single curvature, not the end actions of a stiffness analysis, which flip sign at one end**; opposite signs read as double curvature, so the sheet warns `double-curvature` with the C₁ and C_my the run uses, an entered value shown against the ψ value, and a two-point sketch of the diagram), `N_Ed` (tension positive, compression negative, as S2/S3; a positive value is outside the range, so the sheet has no tension branch), `M_y_Ed` (link from S2 `M_abs_e1` or S5) and `psi_y` (**default 1, a uniform moment, conservative**; both optional because the end-moment mode does not use them — a blank one in ψ mode warns and takes the default), `M_z_Ed`, `psi_z`, optional `C_m_y`, `C_m_z`, `C_m_LT`; buckling `L_cr_y`, `L_cr_z`, `curve_y`, `curve_z` (default `auto`). A `z_g` with `C_2 = 0` has no effect and warns (`zg-c2`).

**Outputs.** `C_1`, `Mcr`, `lambda_LT`, `alpha_LT`, `Phi_LT`, `chi_LT`, `Mb_Rd`, `N_Rk`, `N_cr_y`, `N_cr_z`, `lambda_y`, `lambda_z`, `chi_y`, `chi_z`, `N_b_y_Rd`, `N_b_z_Rd`, `N_b_Rd`, `k_yy`, `k_yz`, `k_zy`, `k_zz`, `C_my`, `C_mz`, `C_mLT`, `u_LTB`, `u_buckling`, `u_61`, `u_62`, `u_interaction`, `u_member`, `governing`. **Ports.** `Mb_Rd` (the brief's `ltb.Mb_Rd`), `u_interaction` (`member.util_interaction`), `u_member`, `Mcr`, `chi_LT`, `lambda_LT`, `N_b_Rd`, `u_LTB`. **Checks.** LTB; flexural buckling; equations 6.61 and 6.62 (governing first). Links: S1 (section), S2 and S5 (moment, axial force), S3, S8 (spreader beam).
