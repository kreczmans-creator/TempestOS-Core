The standard Tempest action control — uppercase display type, wide tracking, squared corners; use for every clickable action.

```jsx
<Button variant="primary" iconLeft={<Icon name="play" size={14} />}>Deploy</Button>
<Button variant="secondary" size="sm">Cancel</Button>
<Button variant="primary" size="lg" notch>Request access</Button>
```

One primary per view. `notch` is reserved for marketing hero CTAs. Danger is destructive confirmation only.
