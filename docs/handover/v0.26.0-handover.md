### What was built

- Result linking (L1): outputs link to inputs, including single cells of a table. A link is pinned to a revision, checks dimensions, refuses cycles and chains over 20, and marks everything downstream stale. A stale calculation cannot be checked or issued; "Update linked inputs" or "Update to revision n" mends it.
- Calculation packs: five built-in pack templates (drive train, motor circuit, wet heating, enclosure cooling, steel support) with example inputs, checked once and issued as one bundle. Five pack worked examples under `docs/worked-examples/packs/`.

- Reference records with a licence lock. A licensed record's values never leave in an export; issued sheets withhold a licensed table's rows; a withheld value cannot be re-imported until the record is applied again. No record ships with the product.
- Independent check on E4, E5 and S6: the creator and anyone who set or changed an input cannot check.
- Reviews: Security, Red, Green, Black, Blue (two rounds), Purple, Yellow, White, Grey and Orange each have an Addendum A section in `docs/reviews/`. No Critical or High finding is open. DA-17 to DA-24 record the decisions.
- Tests on the final code (run on Linux): Engine 384, Sheets 111, Library 168 passed and 1 skipped (D-32), Calculators 869. The Desktop and Core suites were not re-run for this section.

### Known limitations

- **C-2 is not in this build.** Sheet layout, wording, units and decimals will change when it merges. The test values file is regenerated then. The pack names sets and files, so it stays right.
- **The long-form scripts in the pack were written before C-1.** Their numbers and versions are not re-verified. The pack tells you how to read a difference. The test values file and the pack READMEs hold the current numbers.
- **The Guided test covers the worked examples and the manual steps.** It has no step for the demo, the dashboard or the long-form scripts. 14 sets are left to you. A guided result reaches the dashboard only from a finished run on the current script.
- **The dashboard reads an embedded snapshot.** Regenerate it after a document changes (`python3 scripts/generate-verification-snapshot.py`). Chains show *Not tested* in the manual column. A Blocked result shows as *Partly passed*.
- **The demo.** It installs as drafts and is never checked for you. An issued demo record is never deleted, so Remove then refuses. Removing it leaves soft-deleted objects behind, about 780 KiB for each install and removal. Two app windows on one database could each install it (RR-C-06).
- **Records.** 7 templates have no record kind. 8 kinds have no template. Three lifting kinds have none. The record lock follows the provenance, not the numbers (DA-18).
- **Template versions.** A calculation checked or issued on an older template version keeps its stored sheet. It cannot be re-run after a version bump (DC-14).
- **Signatures are not authenticated.** **Switch person…** needs no password. S8 and the lifting lug stay behind the flag for that reason.
- **The soak** sees leaks that outlive a host. It also sees a service that keeps about 32 KiB or more for each item. It does not see the screens.
- **Markdown size.** The consolidated pack is about 6,000 lines. It keeps every earlier test. CONTRIBUTING limits the Markdown a pull request adds.
