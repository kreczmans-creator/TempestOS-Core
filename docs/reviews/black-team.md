## Summary
Counts: **High 4** (B-01, B-12, B-13, B-17), **Medium 7** (B-02, B-03, B-14, B-15, B-18, B-19, B-20), **Low 11** (B-04–B-09, B-16, B-21–B-24), **Info 3** (B-10, B-11, B-25). All 32 worked examples match their stored sheets through the public path; no exception escaped the Calc API in 55 misuse cases; one timing-flaky Calculators test and 3 build warnings against a "0 warnings" promise.

Fix first:
1. **B-12/B-13** — a rejected check, or a check of a draft that lacks provenance, leaves the calculation in a state that can never be issued or corrected (instance Draft vs evidence Checked; Checked with no way back to Draft).
2. **B-01/B-15** — missing, malformed or mis-named inputs silently fall back to template defaults and produce a PASSing sheet; a new user cannot tell a computed sheet from a defaulted one except by reading `Source = default` row by row.
3. **B-17/B-18** — table inputs (nodes, elements, loads, vertices) are not reproduced on the sheet, and checks print utilisation ratios as if they were demands (`C_pk against target: 3.99 vs 1` for a C_pk of 0.33), so the sheet cannot be checked independently as the product promises.
