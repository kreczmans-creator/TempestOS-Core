1. SCOPE AND METHOD
Hole and shaft limits for a nominal size and tolerance classes, the resulting fit (clearance, transition or interference) and its extreme values, from the ISO 286-1 formulae.
i = 0.45·D^(1/3) + 0.001·D (µm) at the geometric mean D of the size step; ITn = multiplier × i; fundamental deviations by letter from the published formulae; hole deviations by the general rule (EI = −es for A–H; ES = −ei + Δ for K–ZC). Limits = nominal + deviations; fit extremes from the limits.
  Ref: ISO 286-1:2010 §4, §5 — Bases of tolerances, deviations and fits — tolerance grades and fundamental deviations
  Ref: ISO 286-2:2010 — Tables of standard tolerance classes and limit deviations (not reproduced)

2. INPUTS
  Symbol | Description | Value | Unit | Source | Valid range
  D | Nominal size | 50 | mm | drawing: DRG-HUB-04 rev C | 1 … 500 mm
  hole_letter | Hole fundamental deviation letter | H |  | spec: DRG-HUB-04: H7/p6 | any
  hole_grade | Hole IT grade | 7 |  | spec: DRG-HUB-04: H7/p6 | 5 … 11
  shaft_letter | Shaft fundamental deviation letter | p |  | spec: DRG-HUB-04: H7/p6 | any
  shaft_grade | Shaft IT grade | 6 |  | spec: DRG-HUB-04: H7/p6 | 4 … 11

3. ASSUMPTIONS
  A1. IT values and fundamental deviations are the unrounded results of the ISO 286-1 formulae at the geometric mean of the size step. (The tabulated values apply the standard's own rounding and may differ by about 1 µm; enter overrides from a released reference record where the tabulated value governs.)
  A2. Hole deviations follow the general rule from the shaft deviations, with Δ = ITn − IT(n−1) where the standard applies it. (Table-specific departures in the standard are not reproduced; use the overrides where they govern.)

4. WORKING
  [6] D_step = size step (lower, upper]    « ISO 286-1 §4
      = (30, 50] mm
      = 38.73 mm
        Geometric mean of the size step
  [7] i = 0.45·D^(1/3) + 0.001·D    « ISO 286-1 §5
      = D = 38.73 mm
      = 1.5612 µm
        Standard tolerance unit
  [8] IT_hole = IT7    « ISO 286-1 §5
      = 16 × i
      = 24.98 µm
        Hole tolerance
  [9] IT_shaft = IT6    « ISO 286-1 §5
      = 10 × i
      = 15.612 µm
        Shaft tolerance
  [10] es = ei + IT_shaft    « ISO 286-1 §5
      = 24.98 + 15.612
      = 40.592 µm
        Shaft upper deviation
  [11] ei = fundamental deviation 'p'    « ISO 286-1 §5
      = +IT7
      = 24.98 µm
        Shaft lower deviation
  [12] ES = EI + IT_hole    « ISO 286-1 §5
      = 0 + 24.98
      = 24.98 µm
        Hole upper deviation
  [13] EI = fundamental deviation 'H'    « ISO 286-1 §5
      = −es of the same letter
      = 0 µm
        Hole lower deviation
  [14] D_hole_max = D + ES
      = 50 mm + 24.98 µm
      = 50.025 mm
        Hole maximum
  [15] D_hole_min = D + EI
      = 50 mm + 0 µm
      = 50 mm
        Hole minimum
  [16] d_shaft_max = D + es
      = 50 mm + 40.592 µm
      = 50.041 mm
        Shaft maximum
  [17] d_shaft_min = D + ei
      = 50 mm + 24.98 µm
      = 50.025 mm
        Shaft minimum
  [18] c_max = ES - ei
      = 24.98 µm − 24.98 µm
      = 0 µm
        Maximum clearance (negative: minimum interference)
  [19] c_min = EI - es
      = 0 µm − 40.592 µm
      = -40.592 µm
        Minimum clearance (negative: maximum interference)
  [20] i_max = es - EI
      = 40.592 µm − 0 µm
      = 40.592 µm
        Maximum interference
  [21] i_min = ei - ES
      = 24.98 µm − 24.98 µm
      = 0 µm
        Minimum interference (negative: maximum clearance)
  [22] fit = fit class
      = H7/p6
      = "interference"
        Fit kind: clearance, transition or interference
  [23] c_mean = (c_max + c_min) / 2
      = (0 µm + -40.592 µm) / 2
      = -20.296 µm
        Mean clearance
