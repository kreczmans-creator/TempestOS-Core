1. Scope and method
Calculates the limits of size of a hole and a shaft for a nominal size and ISO 286 tolerance classes, and the resulting fit with its extreme clearances and interferences. It uses the ISO 286-1 formulae, not the tables.
Standard tolerance factor at the geometric mean D of the size step: i = 0.45·D^(1/3) + 0.001·D (µm). Width of the tolerance band for the grade: ITn = multiplier × i. Fundamental deviations by letter from the published formulae, and hole deviations by the general rule: EI_hole = −es_shaft (A–H); ES_hole = −ei_shaft + Δ (K–ZC). Limits of size of the hole and the shaft: limit = nominal + deviation. Fit extremes, the largest and smallest clearance (negative is interference): c_max = ES_hole − ei_shaft; c_min = EI_hole − es_shaft. Rolling-bearing bore mode: a bearing bore is not an ISO 286 hole; it has its own tolerance (ISO 492) lying below nominal, so ES_hole and EI_hole are entered from the bearing record instead of being computed.

2. Inputs

3. Assumptions
  A1. IT values and deviations are the unrounded results of the ISO 286-1 formulae at the size step's geometric mean. (The tables apply the standard's own rounding, so tabulated values differ by about 1 µm for the letters a to n.)
  A2. For the letters p to zc the formula value can lie several µm below the tabulated deviation. (The tables add their own increments and sub-steps, so p6 at 450 mm is 62.2 µm from the formula against 68 µm tabulated.)
  A3. Hole deviations follow the general rule from the shaft deviations, with Δ where the standard applies it. (Δ is ITn − IT(n−1), and the standard's table-specific departures are not reproduced.)

4. Working
  [7] D_step = size step (lower, upper]    « ISO 286-1 §4
      = (18, 30] mm
      = 23.238 mm
        Geometric mean of the size step
  [8] i = 0.45·D^(1/3) + 0.001·D    « ISO 286-1 §5
      = D = 23.238 mm
      = 1.3074 µm
        Standard tolerance unit
  [9] IT_hole = IT7    « ISO 286-1 §5
      = 16 × i
      = 20.918 µm
        Hole tolerance
  [10] IT_shaft = IT6    « ISO 286-1 §5
      = 10 × i
      = 13.074 µm
        Shaft tolerance
  [11] es_shaft = fundamental deviation 'g'    « ISO 286-1 §5
      = −2.5·D^0.34
      = -7.2853 µm
        Shaft upper deviation
  [12] ei_shaft = es_shaft − IT_shaft    « ISO 286-1 §5
      = -7.2853 − 13.074
      = -20.359 µm
        Shaft lower deviation
  [13] ES_hole = EI_hole + IT_hole    « ISO 286-1 §5
      = 0 + 20.918
      = 20.918 µm
        Hole upper deviation
  [14] EI_hole = fundamental deviation 'H'    « ISO 286-1 §5
      = −es_shaft of the same letter
      = 0 µm
        Hole lower deviation
  [15] D_hole_max = D + ES_hole
      = 25 mm + 20.918 µm
      = 25.021 mm
        Hole maximum
  [16] D_hole_min = D + EI_hole
      = 25 mm + 0 µm
      = 25 mm
        Hole minimum
  [17] d_shaft_max = D + es_shaft
      = 25 mm + -7.2853 µm
      = 24.993 mm
        Shaft maximum
  [18] d_shaft_min = D + ei_shaft
      = 25 mm + -20.359 µm
      = 24.98 mm
        Shaft minimum
  [19] c_max = ES_hole - ei_shaft
      = 20.918 µm − (-20.359 µm)
      = 41.277 µm
        Maximum clearance (negative: minimum interference)
  [20] c_min = EI_hole - es_shaft
      = 0 µm − (-7.2853 µm)
      = 7.2853 µm
        Minimum clearance (negative: maximum interference)
  [21] i_max = es_shaft - EI_hole
      = (-7.2853 µm) − 0 µm
      = -7.2853 µm
        Maximum interference
  [22] i_min = ei_shaft - ES_hole
      = (-20.359 µm) − 20.918 µm
      = -41.277 µm
        Minimum interference (negative: maximum clearance)
  [23] fit = fit class
      = H7/g6
      = "clearance"
        Fit kind: clearance, transition or interference
  [24] c_mean = (c_max + c_min) / 2
      = (41.277 µm + 7.2853 µm) / 2
      = 24.281 µm
        Mean clearance
