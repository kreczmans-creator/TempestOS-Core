1. Scope and method
Calculates the torque, speed and power a motor needs to move a load through a mechanism, and checks a candidate motor against them. A continuously running rotary load is sized from its steady torque, speed and run-up time.
Linear mechanism: k = p/(2π i) (screw), D/(2 i) (belt), D_p/(2 i) (rack), in metres per motor radian; J_refl = m k²/η; T_load = F k/η, with F = m g (sin θ + μ cos θ) + F_p Rotary mechanism through a gearbox: J_refl = J_L/(i² η); T_load = T_L/(i η) Move profile: trapezoidal v_pk = s/(t_move − t_acc), a = v_pk/t_acc; S-curve (sine acceleration, same peak speed) a_pk = (π/2) a_trap Peak torque: T_acc = J_total α; T_pk = T_acc + T_load; T_dec = −T_acc + T_load; the check is SF·max(|T_pk|, |T_dec|) ≤ T_peak; braking power P_brake = max(0, −T_dec·ω_pk) Thermal duty: T_rms = √(Σ T_i² t_i / t_cycle) over the whole cycle, the dwell at T_hold = m g sin θ·k for a linear mechanism not held by a brake; P_rms = ω_pk √{[t_acc·(2/3)(T_load² + T_acc²) + T_load² t_const]/t_cycle}, and for the S-curve the acceleration term is t_acc·[(3/4) T_load² + (5/16) T_acc²] Output side and design torque: T_alt = (T_pk − T_dec)/2 (0 in continuous duty); T_out = T·i·η and n_out = n_pk/i for a rotary mechanism; F_ax_pk = F_load + m a_pk for a ball screw; T_design on the basis T_basis (load peak max(|T_pk|, |T_dec|), T_peak, SF_c·T_rated or T_lim) Continuous rotary duty: ω = 2π n_L i/60, n_pk = n_L i; T_load = T_L/(i η), T_rms = T_load; T_pk = J_total ω/t_start + T_load; P_cont = T_load ω, P_rms = P_cont Rated power of the candidate motor: P_rated = T_rated·2π n_rated/60 (without n_rated there is no P_rated); the check is P_cont ≤ P_rated, u_power = P_cont/P_rated

3. Assumptions
  A1. The transmission is rigid. (Servo-sizing practice.)
  A2. The mechanism efficiency applies to the driving direction and is also used in the deceleration phase. (Servo-sizing practice.)
  A3. This is conservative for the peak and slightly pessimistic for the RMS torque. (Servo-sizing practice.)
  A4. The friction force is Coulomb friction on the moved mass. (Load model.)
  A5. Viscous and breakaway friction are not modelled unless included in F_p. (Load model.)
  A6. In continuous duty the load torque is constant at the stated speed. (Run-up idealisation for pumps and fans.)
  A7. The motor accelerates the whole inertia linearly to speed in t_start while carrying the full load torque, which is conservative. (Run-up idealisation for pumps and fans.)
  A8. Continuous duty ignores the move distance, move time, acceleration fraction, dwell and profile. (Run-up idealisation for pumps and fans.)
  A9. The S-curve profile has sine-shaped acceleration over the same acceleration time. (Jerk-limited profile idealisation.)
  A10. The peak acceleration of the S-curve profile is π/2 times the trapezoidal value. (Jerk-limited profile idealisation.)
  A11. profile (Motion profile) is taken as trapezoidal. (Sheet default value; no project figure given.)
  A12. T_basis (Design torque basis for downstream couplings (T_design): the load's peak (the larger of the accelerating and the braking torque, in magnitude), the motor's typed peak torque, a service factor on the rated torque, or a protective limit such as a torque limiter) is taken as Load peak (T_pk). (Sheet default value; no project figure given.)
  A13. brake (A brake or a self-locking drive holds a linear axis during the dwell (no holding torque); unticked, a vertical or inclined axis is held by the motor) is taken as no. (Sheet default value; no project figure given.)

4. Working
  [19] k = 1 / i
      = 1 / 1
      = 1
        Output radians per motor radian
  [20] T_load = T_L / (i * eta)
      = 76.973 N·m / (1 × 0.99)
      = 77.751 N·m
        Load torque at the motor shaft (constant)
  [21] J_refl = J_L / (i^2 * eta)
      = 0.004 kg·m² / (1^2 × 0.99)
      = 0.0040404 kg·m²
        Load inertia reflected to the motor shaft
  [22] omega_pk = n_L * i
      = 1450 rpm × 1
      = 151.84 rad/s
        Motor speed, n_L · i
  [23] J_total = J_motor + J_mech + J_refl
      = 0.1 kg·m² + 0.001 kg·m² + 0.0040404 kg·m²
      = 0.10504 kg·m²
        Total inertia at the motor shaft
  [24] alpha_pk = omega_pk / t_start
      = 151.84 rad/s / 2 s
      = 75.922 rad/s²
        Run-up angular acceleration (to speed in t_start)
  [25] T_acc = J_total * alpha_pk
      = 0.10504 kg·m² × 75.922 rad/s²
      = 7.9749 N·m
        Run-up (acceleration) torque
  [26] T_pk = T_acc + T_load
      = 7.9749 N·m + 77.751 N·m
      = 85.725 N·m
        Peak torque: run-up carrying the full load (conservative)
  [27] T_rms = T_load
      = 77.751 N·m
      = 77.751 N·m
        RMS torque: continuous running at the load torque
  [28] T_alt = 0 N*m
      = 0 N·m
        Alternating torque amplitude: none, continuous running is steady (the run-up is a rare peak, T_pk)
  [30] T_design = T_pk
      = 85.725 N·m
      = 85.725 N·m
        Design torque: the load's peak torque (run-up included; continuous duty has no deceleration)
  [31] F_ax_pk = 0 N
      = 0 N
        Peak axial thrust on the bearings (none for a rotary mechanism)
  [32] T_hold = 0 N*m
      = 0 N·m
        Holding torque in the dwell: none, continuous running has no dwell
  [33] P_brake = 0 kW
      = 0 kW
        Peak braking power: none in continuous duty
  [34] n_pk = omega_pk
      = 151.84 rad/s
      = 1450 rpm
        Motor speed
  [35] T_out_m = T_load * i * eta
      = 77.751 N·m × 1 × 0.99
      = 76.973 N·m
        Mean torque on the output shaft (the constant load torque)
  [36] T_out_a = T_alt * i * eta
      = 0 N·m × 1 × 0.99
      = 0 N·m
        Alternating torque amplitude on the output shaft
  [37] T_out_pk = T_pk * i * eta
      = 85.725 N·m × 1 × 0.99
      = 84.868 N·m
        Peak torque on the output shaft (the motor rotor's inertia torque is counted, so conservative)
  [38] n_out = n_pk / i
      = 1450 rpm / 1
      = 1450 rpm
        Output shaft speed
  [39] P_cont = T_load * omega_pk
      = 77.751 N·m × 151.84 rad/s
      = 11.806 kW
        Continuous shaft power at the motor
  [41] P_rated = T_rated * n_rated
      = 120 N·m × 1460 rpm
      = 18.347 kW
        Rated (nameplate) shaft power of the candidate motor: its rated torque times its rated speed
  [42] u_power = P_cont / P_rated
      = 11.806 kW / 18.347 kW
      = 0.64348
        Continuous shaft power against the rated power of the candidate motor
  [43] P_pk = T_pk * omega_pk
      = 85.725 N·m × 151.84 rad/s
      = 13.017 kW
        Peak mechanical power (end of the run-up)
  [44] n_mean = omega_pk
      = 151.84 rad/s
      = 1450 rpm
        Mean motor speed: the steady running speed
  [45] P_rms = P_cont
      = 11.806 kW
      = 11.806 kW
        RMS mechanical power: the steady running power (thermal-equivalent continuous power)
  [46] J_ratio = (J_refl + J_mech) / J_motor
      = (0.0040404 kg·m² + 0.001 kg·m²) / 0.1 kg·m²
      = 0.050404
        Inertia ratio (load : motor)
  [47] T_pk_sf = SF * T_pk
      = 1.25 × 85.725 N·m
      = 107.16 N·m
        Peak torque with the safety factor
  [48] T_rms_sf = SF * T_rms
      = 1.25 × 77.751 N·m
      = 97.188 N·m
        RMS torque with the safety factor
  [49] u_peak = SF * T_pk / T_peak
      = 1.25 × 85.725 N·m / 275 N·m
      = 0.38966
        Peak torque utilisation with safety factor
  [50] u_rms = SF * T_rms / T_rated
      = 1.25 × 77.751 N·m / 120 N·m
      = 0.8099
        Continuous torque utilisation with safety factor
  [51] u_speed = n_pk / n_max
      = 1450 rpm / 3000 rpm

      = 1450 rpm / 1460 rpm

        Motor speed over the rated (nameplate) speed
