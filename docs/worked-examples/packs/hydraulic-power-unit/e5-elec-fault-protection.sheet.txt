1. Scope and method
Automatic disconnection of supply in a TN system for one circuit: the earth fault loop impedance at the conductor's operating temperature against the device's maximum, the disconnection time, the protective conductor (and line conductor) against the adiabatic minimum, and the prospective three-phase fault at the origin against the device's breaking capacity.
Loop impedance: Z_s = Z_e + (R_1 + R_2)·[1 + α(θ − 20)], R = k_R·ρ_20·L/S (k_R = 1.125 takes the pure-copper ρ_20 to the cable standard's maximum conductor resistance; k enters with the pure ρ_20) Fault current: I_f = C_min·U_0/Z_s, C_min = 0.95 Maximum loop impedance: Z_s,max = C_min·U_0/I_a; I_a = 5, 10 or 20·I_n for MCB types B, C, D, or read from the time–current points at t_req (log-log) Adiabatic conductor check: S_min = √(I²t)/k, k = √[Q_c(β + 20)/ρ_20 · ln(1 + (θ_f − θ_i)/(β + θ_i))] (derived); I²t = I_f²·t_d from 0.1 s; below 0.1 s the device's let-through I²t at the maximum prospective fault, which bounds the protective and the line conductor at the origin where the earth-fault current is largest (reg. 434.5.2, 543.1.3); without it neither is checked at the origin, the sheet fails 'Conductors against let-through at the origin' and the protective conductor check uses I_f²·0.1 s at the end-of-line fault only Protective device check: the device chosen here must be the one carried from the cable step (device_code 1 = MCB B, 2 = C, 3 = D, 4 = fuse or MCCB), else the sheet is blocked Fault level (simplified): Z_T = u_k·U_n²/S_r, I_k3 = c·U_n/(√3·Z_T), U_n = √3·U_0

3. Assumptions
  A1. TN system, a single earth fault of negligible impedance; no motor contribution, arc fault or IT system. (Scope of the check.)
  A2. Line and protective conductors are the same material at the same temperature; R = ρ₂₀·L/S corrected by α. (Conductor data from a material record.)
  A3. k is derived from the material constants and labelled derived; it is not read from a licensed table. (Derived constants, not read from a table.)
  A4. Fuse and MCCB characteristics are points the user reads off the manufacturer's curve (log-log interpolation; no extrapolation). (No time–current table ships.)
  A5. Optional field-test value 0.8 × Z_s,max is a rule of thumb for measurements at ambient temperature. (Labelled on the sheet.)
  A6. The line conductor check (reg. 434.5.2) needs the device's let-through energy at the maximum prospective fault; the end-of-line earth fault is the minimum fault and does not bound it, so the check is made only when I2t_let is entered or the disconnection time is 0.1 s or more. (Stated limitation: the end-of-line earth fault is the minimum fault, not the maximum.)
  A7. C_min (Voltage factor C_min) is taken as 0.95. (Sheet default value; no project figure given.)
  A8. c_max (Voltage factor c for the maximum fault) is taken as 1.1. (Sheet default value; no project figure given.)
  A9. rho_20 (Resistivity at 20 °C (used for k, and for R₁ + R₂ through k_R)) is taken as 0.000017241 Ω·mm. (Sheet default value; no project figure given.)
  A10. k_R (Conductor resistance factor on ρ₂₀ for R₁ + R₂ (1 = the resistivity itself; the cable standard's maximum conductor resistances are 5 to 12 % above pure copper, so the default is 1.125 and Z_s is not understated; k is not changed by it)) is taken as 1.125. (Sheet default value; no project figure given.)
  A11. alpha (Temperature coefficient of resistance) is taken as 0.00393 1/K. (Sheet default value; no project figure given.)
  A12. Q_c (Volumetric heat capacity) is taken as 0.00345 J/(K·mm³). (Sheet default value; no project figure given.)
  A13. beta (Reciprocal temperature coefficient β) is taken as 234.5 K. (Sheet default value; no project figure given.)
  A14. theta_i (Initial temperature for the adiabatic check) is taken as 70 °C. (Sheet default value; no project figure given.)
  A15. theta_f (Final temperature for the adiabatic check) is taken as 160 °C. (Sheet default value; no project figure given.)

4. Working
  [20] R_12 = rho_20 * k_R * L * (1 / S_line + 1 / S_cpc) * (1 + alpha * (theta - 20 degC))
      = 0.000017241 ohm·mm × 1.125 × 30 m × (1 / 10 mm² + 1 / 10 mm²) × (1 + 0.00393 1/K × (70 degC − 20 degC))
      = 0.13924 ohm
        R₁ + R₂ at the conductor temperature
  [21] Z_s = Z_e + R_12    « BS 7671 reg. 411.4.4
      = 0.05 ohm + 0.13924 ohm
      = 0.18924 ohm
        Earth fault loop impedance
  [22] I_f = C_min * U_0 / Z_s
      = 0.95 × 230 V / 0.18924 ohm
      = 1154.6 A
        Earth fault current
  [23] I_a = 10 * I_n    « BS EN 60898-1
      = 10 × 40 A
      = 400 A
        Instantaneous tripping current (10 I_n)
  [24] Z_s_max = C_min * U_0 / I_a    « BS 7671 reg. 411.4.4
      = 0.95 × 230 V / 400 A
      = 0.54625 ohm
        Maximum earth fault loop impedance
  [25] u_Zs = Z_s / Z_s_max
      = 0.18924 ohm / 0.54625 ohm
      = 0.34644
        Loop impedance utilisation
  [26] Z_test = 0.8 * Z_s_max
      = 0.8 × 0.54625 ohm
      = 0.437 ohm
        Field-test maximum at ambient (0.8 × Z_s,max, rule of thumb)
  [27] t_d = instantaneous region (I_f ≥ I_a): t ≤ 0.1 s
      = I_f = 1154.6 A
      = 0.1 s
        Disconnection time
  [29] I2t = device let-through I²t at the maximum prospective fault
      = 80000 A²s
      = 80000 A²·s
        Fault energy (let-through below 0.1 s)
  [30] k = √[Q_c(β + 20)/ρ₂₀ · ln(1 + (θ_f − θ_i)/(β + θ_i))] (derived)    « BS 7671 reg. 543.1.3
      = √[0.00345 × 254.5 / 0.000017241 × ln(1 + 90/304.5)]
      = 114.84
        Adiabatic factor k, A·√s/mm² (derived, compare with the licensed table)
  [31] S_min = √(I²t)/k    « BS 7671 reg. 543.1.3, 434.5.2
      = √80000 / 114.84
      = 2.463 mm²
        Minimum conductor cross-section (adiabatic)
  [32] u_cpc = S_min / S_cpc
      = 2.463 mm² / 10 mm²
      = 0.2463
        Protective conductor utilisation
  [33] u_line = S_min / S_line
      = 2.463 mm² / 10 mm²
      = 0.2463
        Line conductor utilisation (same fault energy)
  [36] U_n = sqrt(3) * U_0
      = sqrt(3) × 230 V
      = 398.37 V
        Line voltage
  [37] Z_T = u_k * U_n^2 / S_r
      = 4 % × (398.37 V)^2 / 400 kVA
      = 0.01587 ohm
        Transformer impedance
  [38] I_k3 = c_max * U_n / (sqrt(3) * Z_T)    « IEC 60909-0 cl. 5.3
      = 1.1 × 398.37 V / (sqrt(3) × 0.01587 ohm)
      = 15.942 kA
        Prospective three-phase fault at the origin (simplified)
  [39] c_k3 = c_max    « IEC 60909-0 cl. 5.3
      = 1.1
      = 1.1
        Voltage factor c of the prospective fault current
  [41] u_Icn = I_k3 / I_cn
      = 15.942 kA / 25 kA
      = 0.63768
        Breaking capacity utilisation
