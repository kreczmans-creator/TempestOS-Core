1. SCOPE AND METHOD
Single-phase heat exchanger with constant properties: in rating mode the duty and outlet temperatures for a given area; in sizing mode the area for a given duty. Counterflow, parallel flow, 1-shell-pass shell and tube, crossflow with both fluids unmixed (approximate), and one fluid at constant temperature.
Capacity rates: C_h = ṁ_h·c_p,h, C_c = ṁ_c·c_p,c, C_r = C_min/C_max Overall coefficient with fouling: U_f = 1/(1/U + R_f) Transfer units: NTU = U_f·A/C_min; effectiveness ε(NTU, C_r) for the arrangement Duty: Q = ε·C_min·(T_h,in − T_c,in); outlets from the energy balance Sizing: ε = Q/(C_min·ΔT_max), NTU from the inverse relation, A = NTU·C_min/U_f Cross-check: Q = U_f·A·F·ΔT_lm, F from R and P (1 shell pass) or back-calculated
  Ref: Incropera, Fundamentals of Heat and Mass Transfer 7th ed., §11.3–11.5, Tables 11.3–11.4 — LMTD and effectiveness-NTU methods
  Ref: Çengel & Ghajar, Heat and Mass Transfer 5th ed., Ch. 11 — Heat exchangers

3. ASSUMPTIONS
  A1. Single phase on both sides (except the C_r = 0 arrangement), constant properties, no heat loss to surroundings. (Incropera 7th ed. §11.3–11.4.)
  A2. The crossflow both-unmixed effectiveness is the published approximate correlation, flagged on the sheet. (Incropera 7th ed. Table 11.3.)
  A3. Specific heats are user records (or B2 for air) at the mean temperature of each stream. (§A3 reference records.)
  A4. cp_h (Hot-side specific heat) is taken as 4180 J/(kg*K). (Sheet default value; no project figure given.)
  A5. cp_c (Cold-side specific heat) is taken as 4180 J/(kg*K). (Sheet default value; no project figure given.)
  A6. dT_min (Minimum approach temperature difference) is taken as 2 K. (Sheet default value; no project figure given.)

4. WORKING
  [12] C_h = m_h * cp_h
      = 0.3 kg/s × 4180 J/(kg·K)
      = 1254 W/K
        Hot-side capacity rate
  [13] C_c = m_c * cp_c
      = 0.25 kg/s × 4180 J/(kg·K)
      = 1045 W/K
        Cold-side capacity rate
  [14] C_min = min(C_h, C_c)
      = min(1254 W/K, 1045 W/K)
      = 1045 W/K
        Minimum capacity rate
  [15] C_r = min(C_h, C_c) / max(C_h, C_c)
      = min(1254 W/K, 1045 W/K) / max(1254 W/K, 1045 W/K)
      = 0.83333
        Capacity ratio
  [16] U_f = 1 / (1 / U + R_f)
      = 1 / (1 / 1000 W/(m²·K) + 0.0001 m²·K/W)
      = 909.09 W/(m²·K)
        Overall coefficient with fouling
  [18] eps = Q_req / (C_min·ΔT_max)
      = 3422.4 / (1045 × 16)
      = 0.20469
        Effectiveness required
  [19] NTU = NTU(ε, C_r) inverse relation    « Incropera 7th ed. Table 11.4
      = ε = 0.20469, C_r = 0.83333
      = 0.252
        Transfer units required
  [20] A_req = NTU·C_min / U_f
      = 0.252 × 1045 / 909.09
      = 0.28968 m²
        Required heat transfer area
  [21] UA = NTU·C_min
      = 0.252 × 1045
      = 263.34 W/K
        Required UA
  [22] Q = ε·C_min·(T_h,in − T_c,in)
      = 0.20469 × 1045 × 16
      = 3.4224 kW
        Heat duty
  [23] T_h_out = T_h,in − Q/C_h
      = 38 °C − 3422.4 / 1254
      = 35.271 degC
        Hot-side outlet temperature
  [24] T_c_out = T_c,in + Q/C_c
      = 22 °C + 3422.4 / 1045
      = 25.275 degC
        Cold-side outlet temperature
  [25] dT_c = T_c,out − T_c,in = Q/C_c
      = 3422.4 / 1045
      = 3.275 K
        Cold-side temperature rise
  [26] T_c_m = (T_c,in + T_c,out)/2
      = (22 °C + 25.275 °C)/2
      = 23.638 degC
        Mean cold-side temperature
  [27] dT_app = min(T_h,in − T_c,out, T_h,out − T_c,in)
      = 12.725 K
      = 12.725 K
        Approach temperature difference
  [28] dT_lm = (ΔT_1 − ΔT_2)/ln(ΔT_1/ΔT_2), counterflow ends
      = ΔT_1 = 12.725 K, ΔT_2 = 13.271 K
      = 12.996 K
        Log-mean temperature difference
  [29] F = 1 (pure counterflow, parallel flow or C_r = 0)    « Incropera 7th ed. §11.3
      = R = 0.83333, P = 0.20469
      = 1
        LMTD correction factor
  [30] Q_lmtd = U_f·A·F·ΔT_lm
      = 909.09 × 0.28968 × 1 × 12.996
      = 3.4224 kW
        Duty by the LMTD method (cross-check)
  [31] u_app = dT_min / dT_app
      = 2 K / 12.725 K
      = 0.15717
        Approach utilisation (minimum / actual)
