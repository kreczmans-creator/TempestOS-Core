1. SCOPE AND METHOD
Automatic disconnection of supply in a TN system for one circuit: the earth fault loop impedance at the conductor's operating temperature against the device's maximum, the disconnection time, the protective conductor (and line conductor) against the adiabatic minimum, and the prospective three-phase fault at the origin against the device's breaking capacity.
Loop impedance: Z_s = Z_e + (R_1 + R_2)·[1 + α(θ − 20)], R = ρ_20·L/S Fault current: I_f = C_min·U_0/Z_s, C_min = 0.95 Maximum loop impedance: Z_s,max = C_min·U_0/I_a; I_a = 5, 10 or 20·I_n for MCB types B, C, D, or read from the time–current points at t_req (log-log) Adiabatic: S_min = √(I²t)/k, k = √[Q_c(β + 20)/ρ_20 · ln(1 + (θ_f − θ_i)/(β + θ_i))] (derived); below 0.1 s the device's let-through I²t Fault level (simplified): Z_T = u_k·U_n²/S_r, I_k3 = c·U_n/(√3·Z_T), U_n = √3·U_0
  Ref: BS 7671:2018 (as amended) reg. 411.3.2.2, 411.3.2.3, 411.4.4 — Automatic disconnection in TN systems: times and the loop impedance condition
  Ref: BS 7671:2018 (as amended) reg. 543.1.3, 434.5.2 — Protective conductor and fault current adiabatic checks
  Ref: BS EN 60204-1:2018 cl. 6.3.3 — Protection by automatic disconnection of supply
  Ref: IEC 60909-0:2016 cl. 5.3 — Voltage factor c

3. ASSUMPTIONS
  A1. TN system, a single earth fault of negligible impedance; no motor contribution, arc fault or IT system. (Scope of the check.)
  A2. Line and protective conductors are the same material at the same temperature; R = ρ₂₀·L/S corrected by α. (Conductor data from a material record.)
  A3. k is derived from the material constants and labelled derived; it is not read from a licensed table. (§A5.)
  A4. Fuse and MCCB characteristics are points the user reads off the manufacturer's curve (log-log interpolation; no extrapolation). (No time–current table ships.)
  A5. Optional field-test value 0.8 × Z_s,max is a rule of thumb for measurements at ambient temperature. (Labelled on the sheet.)
  A6. C_min (Voltage factor C_min) is taken as 0.95. (Sheet default value; no project figure given.)
  A7. c_max (Voltage factor c for the maximum fault) is taken as 1.1. (Sheet default value; no project figure given.)
  A8. theta (Conductor temperature for Z_s) is taken as 70 degC. (Sheet default value; no project figure given.)
  A9. rho_20 (Resistivity at 20 °C) is taken as 0.000017241 ohm*mm. (Sheet default value; no project figure given.)
  A10. alpha (Temperature coefficient of resistance) is taken as 0.00393 1/K. (Sheet default value; no project figure given.)
  A11. Q_c (Volumetric heat capacity) is taken as 0.00345 J/(K*mm^3). (Sheet default value; no project figure given.)
  A12. beta (Reciprocal temperature coefficient β) is taken as 234.5 K. (Sheet default value; no project figure given.)
  A13. theta_i (Initial temperature for the adiabatic check) is taken as 70 degC. (Sheet default value; no project figure given.)
  A14. theta_f (Final temperature for the adiabatic check) is taken as 160 degC. (Sheet default value; no project figure given.)
  A15. device (Protective device) is taken as MCB type B (I_a = 5 I_n). (Sheet default value; no project figure given.)

4. WORKING
  [18] R_12 = rho_20 * L * (1 / S_line + 1 / S_cpc) * (1 + alpha * (theta - 20 degC))
      = 0.000017241 ohm·mm × 25 m × (1 / 1.5 mm² + 1 / 2.5 mm²) × (1 + 0.00393 1/K × (70 degC − 20 degC))
      = 0.5501 ohm
        R₁ + R₂ at the conductor temperature
  [19] Z_s = Z_e + R_12    « BS 7671 reg. 411.4.4
      = 0.35 ohm + 0.5501 ohm
      = 0.9001 ohm
        Earth fault loop impedance
  [20] I_f = C_min * U_0 / Z_s
      = 0.95 × 230 V / 0.9001 ohm
      = 242.75 A
        Earth fault current
  [21] I_a = 5 * I_n    « BS EN 60898-1
      = 5 × 6 A
      = 30 A
        Instantaneous tripping current (5 I_n)
  [22] Z_s_max = C_min * U_0 / I_a    « BS 7671 reg. 411.4.4
      = 0.95 × 230 V / 30 A
      = 7.2833 ohm
        Maximum earth fault loop impedance
  [23] u_Zs = Z_s / Z_s_max
      = 0.9001 ohm / 7.2833 ohm
      = 0.12358
        Loop impedance utilisation
  [24] Z_test = 0.8 * Z_s_max
      = 0.8 × 7.2833 ohm
      = 5.8267 ohm
        Field-test maximum at ambient (0.8 × Z_s,max, rule of thumb)
  [25] t_d = instantaneous region (I_f ≥ I_a): t ≤ 0.1 s
      = I_f = 242.75 A
      = 0.1 s
        Disconnection time
  [26] I2t = I_f²·0.1 s (no let-through entered)
      = 242.75² × 0.1
      = 5892.8 A²·s
        Fault energy (conservative)
  [27] k = √[Q_c(β + 20)/ρ₂₀ · ln(1 + (θ_f − θ_i)/(β + θ_i))] (derived)    « BS 7671 reg. 543.1.3
      = √[0.00345 × 254.5 / 0.000017241 × ln(1 + 90/304.5)]
      = 114.84
        Adiabatic factor k, A·√s/mm² (derived, compare with the licensed table)
  [28] S_min = √(I²t)/k    « BS 7671 reg. 543.1.3, 434.5.2
      = √5892.8 / 114.84
      = 0.66847 mm²
        Minimum conductor cross-section (adiabatic)
  [29] u_cpc = S_min / S_cpc
      = 0.66847 mm² / 2.5 mm²
      = 0.26739
        Protective conductor utilisation
  [30] u_line = S_min / S_line
      = 0.66847 mm² / 1.5 mm²
      = 0.44565
        Line conductor utilisation (same fault energy)
