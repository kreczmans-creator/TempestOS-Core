1. Scope and method
Voltage drop along a circuit in volts and per cent of the nominal voltage, the conductor power loss, and an estimate of the conductor operating temperature, for DC, single-phase and three-phase AC, from resistivity and cross-section (with temperature correction), from tabulated R and X per kilometre, or from a mV/A/m figure; parallel conductors per phase; the drop limit is a user input (the regulatory limits live in BS 7671 Appendix 4 and Regulation 525 and are not embedded).
Conductor resistance at its operating temperature, for n conductors in parallel: R = ρ_T L/(A n), with ρ_T = ρ_20 [1 + α (T_c − 20)]. Resistance and reactance from per-length figures instead: R = R′ L/n; X = X′ L/n. Voltage drop on a DC circuit: ΔV = 2 I R. Voltage drop on a single-phase AC circuit: ΔV = 2 I (R cos φ + X sin φ). Voltage drop on a three-phase AC circuit: ΔV = √3 I (R cos φ + X sin φ). Voltage drop from a tabulated mV/A/m figure, which already carries the 2 or √3: ΔV = (mV/A/m) I L / 1000. Power lost in the cable: P_loss = 2 I² R (DC and single-phase); 3 I² R (three-phase). Estimated conductor temperature at this current: T_c,est = T_amb + (T_rated − T_amb)(I/I_z)².

3. Assumptions
  A1. Balanced load; conductor reactance from the stated X′ (zero when using resistivity alone unless X_km is given); the drop is the arithmetic (R cos φ + X sin φ) form. (Standard engineering approximation.)
  A2. A mV/A/m figure is used as tabulated, with its own temperature and system convention. (Cable table convention.)
  A3. The conductor temperature estimate scales the rated rise with (I/I_z)²; I_z is the user's tabulated value for the installation method and corrections. When the estimate is above T_c the resistance and the drop are computed at the estimate. (BS 7671 Appendix 4 approach, formula only.)
  A4. n_par (Parallel conductors per phase) is taken as 1. (Sheet default value; no project figure given.)
  A5. data (Conductor data from) is taken as resistivity and area. (Sheet default value; no project figure given.)
  A6. rho_20 (Resistivity at 20 °C, the effective value for the conductor resistance (default 0.0194 Ω·mm²/m: the largest class 2 maximum conductor resistance of the cable standard for 1.5 to 120 mm², so the drop is not below the cable tables; pure annealed copper is 0.01724, aluminium 0.0282 Ω·mm²/m)) is taken as 0.0194 Ω·mm²/m. (Sheet default value; no project figure given.)
  A7. alpha (Temperature coefficient of resistance) is taken as 0.00393. (Sheet default value; no project figure given.)
  A8. X_km (Reactance per km per conductor) is taken as 0.08 Ω/km. (Sheet default value; no project figure given.)
  A9. dv_limit (Voltage-drop limit) is taken as 5. (Sheet default value; no project figure given.)
  A10. T_rated (Conductor rated temperature) is taken as 70 °C. (Sheet default value; no project figure given.)

4. Working
  [9] sin_phi = sqrt(1 - cos_phi^2)
      = sqrt(1 − 0.85^2)
      = 0.52678
        sin φ
  [15] rho_T = rho_20 * (1 + alpha * (T_c - 20 degC) / (1 K))
      = 0.0194 ohm·mm²/m × (1 + 0.00393 × (70 degC − 20 degC) / 1 K)
      = 0.023212 ohm·mm²/m
        Resistivity at the operating temperature
  [16] R = rho_T * L / (A_c * n_par)
      = 0.023212 ohm·mm²/m × 25 m / (1.5 mm² × 1)
      = 0.38687 ohm
        Conductor resistance (one conductor, parallel paths combined)
  [17] X = X_km * L / n_par
      = 0.08 ohm/km × 25 m / 1
      = 0.002 ohm
        Conductor reactance
  [18] dV = sqrt(3) * I * (R * cos_phi + X * sin_phi)
      = sqrt(3) × 1.3727 A × (0.38687 ohm × 0.85 + 0.002 ohm × 0.52678)
      = 0.78436 V
        Voltage drop
  [19] dV_pct = 100 * dV / V_n
      = 100 × 0.78436 V / 400 V
      = 0.19609
        Voltage drop, per cent
  [20] P_loss = 3 * I^2 * R
      = 3 × (1.3727 A)^2 × 0.38687 ohm
      = 2.187 W
        Conductor power loss
  [21] u_dv = dV_pct / dv_limit
      = 0.19609 / 5
      = 0.039218
        Drop utilisation against the limit
