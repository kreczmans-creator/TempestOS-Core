1. Scope and method
Calculates the torque, speed and power a motor needs to move a load through a mechanism, and checks a candidate motor against them. A continuously running rotary load is sized from its steady torque, speed and run-up time.
Linear mechanism: k = p/(2π i) (screw), D/(2 i) (belt), D_p/(2 i) (rack), in metres per motor radian; J_refl = m k²/η; T_load = F k/η, with F = m g (sin θ + μ cos θ) + F_p Rotary mechanism through a gearbox: J_refl = J_L/(i² η); T_load = T_L/(i η) Move profile: trapezoidal v_pk = s/(t_move − t_acc), a = v_pk/t_acc; S-curve (sine acceleration, same peak speed) a_pk = (π/2) a_trap Peak torque: T_acc = J_total α; T_pk = T_acc + T_load; T_dec = −T_acc + T_load; the check is SF·max(|T_pk|, |T_dec|) ≤ T_peak; braking power P_brake = max(0, −T_dec·ω_pk) Thermal duty: T_rms = √(Σ T_i² t_i / t_cycle) over the whole cycle, the dwell at T_hold = m g sin θ·k for a linear mechanism not held by a brake; P_rms = ω_pk √{[t_acc·(2/3)(T_load² + T_acc²) + T_load² t_const]/t_cycle}, and for the S-curve the acceleration term is t_acc·[(3/4) T_load² + (5/16) T_acc²] Output side and design torque: T_alt = (T_pk − T_dec)/2 (0 in continuous duty); T_out = T·i·η and n_out = n_pk/i for a rotary mechanism; F_ax_pk = F_load + m a_pk for a ball screw; T_design on the basis T_basis (load peak max(|T_pk|, |T_dec|), T_peak, SF_c·T_rated or T_lim) Continuous rotary duty: ω = 2π n_L i/60, n_pk = n_L i; T_load = T_L/(i η), T_rms = T_load; T_pk = J_total ω/t_start + T_load; P_cont = T_load ω, P_rms = P_cont Rated power of the candidate motor: P_rated = T_rated·2π n_rated/60 (without n_rated there is no P_rated); the check is P_cont ≤ P_rated, u_power = P_cont/P_rated

3. Assumptions
  A1. The transmission is rigid. (Servo-sizing practice.)
  A2. The mechanism efficiency applies to the driving direction and is also used in the deceleration phase. (Servo-sizing practice.)
  A3. This is conservative for the peak and slightly pessimistic for the RMS torque. (Servo-sizing practice.)
  A4. The friction force is Coulomb friction on the moved mass. (Load model.)
  A5. Viscous and breakaway friction are not modelled unless included in F_p. (Load model.)
  A6. In continuous duty the load torque is constant at the stated speed. (Run-up idealisation for pumps and fans.)
  A7. The motor accelerates the whole inertia linearly to speed in t_start while carrying the full load torque, which is conservative. (Run-up idealisation for pumps and fans.)
  A8. Continuous duty ignores the move distance, move time, acceleration fraction, dwell and profile. (Run-up idealisation for pumps and fans.)
  A9. The S-curve profile has sine-shaped acceleration over the same acceleration time. (Jerk-limited profile idealisation.)
  A10. The peak acceleration of the S-curve profile is π/2 times the trapezoidal value. (Jerk-limited profile idealisation.)
  A11. duty_mode (Duty (point-to-point move cycle, or continuous rotary running with a run-up)) is taken as point-to-point. (Sheet default value; no project figure given.)
  A12. profile (Motion profile) is taken as trapezoidal. (Sheet default value; no project figure given.)
  A13. T_basis (Design torque basis for downstream couplings (T_design): the load's peak (the larger of the accelerating and the braking torque, in magnitude), the motor's typed peak torque, a service factor on the rated torque, or a protective limit such as a torque limiter) is taken as Load peak (T_pk). (Sheet default value; no project figure given.)
  A14. brake (A brake or a self-locking drive holds a linear axis during the dwell (no holding torque); unticked, a vertical or inclined axis is held by the motor) is taken as no. (Sheet default value; no project figure given.)
  A15. J_mech (Transmission inertia referred to the motor shaft (screw, pulleys, gearbox, coupling)) is taken as 0.0001 kg·m². (Sheet default value; no project figure given.)
  A16. theta (Incline from horizontal (+ moving uphill)) is taken as 0 °. (Sheet default value; no project figure given.)
  A17. F_p (Process force opposing the move (linear)) is taken as 0 N. (Sheet default value; no project figure given.)
  A18. T_L (Constant load torque at the output (rotary; continuous duty needs it, and a zero value is refused)) is taken as 0 N·m. (Sheet default value; no project figure given.)
  A19. i (Gear ratio (motor : output, 1 = none)) is taken as 1. (Sheet default value; no project figure given.)
  A20. eta (Mechanism efficiency (overall)) is taken as 0.9. (Sheet default value; no project figure given.)
  A21. SF (Safety factor on torque) is taken as 1.25. (Sheet default value; no project figure given.)
  A22. J_ratio_max (Inertia ratio limit (load : motor), warning) is taken as 10. (Sheet default value; no project figure given.)
  A23. f_acc (Acceleration (and deceleration) fraction of the move time) is taken as 0.333333. (Sheet default value; no project figure given.)
  A24. t_dwell (Dwell between moves) is taken as 0.5 s. (Sheet default value; no project figure given.)
  A25. J_motor (Candidate motor rotor inertia) is taken as 0.0002 kg·m². (Sheet default value; no project figure given.)
  A26. T_rated (Candidate motor continuous (rated) torque) is taken as 2 N·m. (Sheet default value; no project figure given.)
  A27. T_peak (Candidate motor peak torque) is taken as 6 N·m. (Sheet default value; no project figure given.)

4. Working
  [22] k = p_screw / (2 * pi * i)
      = 10 mm / (2 × π × 1)
      = 1.5915 mm
        Travel per motor radian
  [23] F_load = m * 9.80665 m/s^2 * (sin(theta) + mu * cos(theta)) + F_p
      = 50 kg × 9.80665 m/s^2 × (sin(0 deg) + 0.1 × cos(0 deg)) + 0 N
      = 49.033 N
        Load force along the motion (gravity, friction, process)
  [25] T_hold = m * 9.80665 m/s^2 * sin(theta) * k
      = 50 kg × 9.80665 m/s^2 × sin(0 deg) × 1.5915 mm
      = 0 N·m
        Holding torque in the dwell: the motor holds the weight of the axis (efficiency not credited)
  [26] T_load = F_load * k / eta
      = 49.033 N × 1.5915 mm / 0.9
      = 0.08671 N·m
        Load torque at the motor shaft
  [27] J_refl = m * k^2 / eta
      = 50 kg × (1.5915 mm)^2 / 0.9
      = 0.00014072 kg·m²
        Load inertia reflected to the motor shaft
  [28] v_pk = s * 1 m / (t_move * (1 - f_acc))
      = 0.5 × 1 m / (0.5 s × (1 − 0.33333))
      = 1.5 m/s
        Peak linear velocity (trapezoid)
  [29] a_trap = v_pk / (f_acc * t_move)
      = 1.5 m/s / (0.33333 × 0.5 s)
      = 9 m/s²
        Trapezoidal acceleration
  [30] omega_pk = v_pk / k
      = 1.5 m/s / 1.5915 mm
      = 942.48 rad/s
        Peak motor speed
  [32] a_pk = a_trap
      = 9 m/s²
      = 9 m/s²
        Peak acceleration
  [33] alpha_pk = a_pk / k
      = 9 m/s² / 1.5915 mm
      = 5654.9 rad/s²
        Peak motor angular acceleration
  [34] J_total = J_motor + J_mech + J_refl
      = 0.0002 kg·m² + 0.0001 kg·m² + 0.00014072 kg·m²
      = 0.00044072 kg·m²
        Total inertia at the motor shaft
  [35] T_acc = J_total * alpha_pk
      = 0.00044072 kg·m² × 5654.9 rad/s²
      = 2.4922 N·m
        Acceleration torque
  [36] T_pk = T_acc + T_load
      = 2.4922 N·m + 0.08671 N·m
      = 2.5789 N·m
        Peak torque (accelerating against the load)
  [37] T_dec = -T_acc + T_load
      = −2.4922 N·m + 0.08671 N·m
      = -2.4055 N·m
        Torque during deceleration
  [38] T_alt = (T_pk - T_dec) / 2
      = (2.5789 N·m − (-2.4055 N·m)) / 2
      = 2.4922 N·m
        Alternating torque amplitude of the cycle about T_load
  [40] T_design = max(abs(T_pk), abs(T_dec))
      = max(abs(2.5789 N·m), abs(-2.4055 N·m))
      = 2.5789 N·m
        Design torque: the load's peak torque, the larger in magnitude of the accelerating T_pk and the braking T_dec (an overhauling drive brakes harder than it accelerates)
  [41] F_ax_pk = F_load + m * a_pk
      = 49.033 N + 50 kg × 9 m/s²
      = 499.03 N
        Peak axial thrust on the screw's support bearings (load force plus the moved mass accelerated)
  [42] n_pk = omega_pk
      = 942.48 rad/s
      = 9000 rpm
        Peak motor speed
  [43] P_pk = T_pk * omega_pk
      = 2.5789 N·m × 942.48 rad/s
      = 2.4306 kW
        Peak mechanical power
  [44] P_brake = max(0 N*m, -T_dec) * omega_pk
      = max(0 N*m, −-2.4055 N·m) × 942.48 rad/s
      = 2.2672 kW
        Peak braking power at the start of the deceleration
  [45] t_acc = f_acc * t_move
      = 0.33333 × 0.5 s
      = 0.16667 s
        Acceleration time
  [46] t_const = t_move - 2 * t_acc
      = 0.5 s − 2 × 0.16667 s
      = 0.16667 s
        Constant-velocity time
  [47] t_cycle = t_move + t_dwell
      = 0.5 s + 0.5 s
      = 1 s
        Cycle time
  [48] n_mean = omega_pk * (t_move - t_acc) / t_cycle
      = 942.48 rad/s × (0.5 s − 0.16667 s) / 1 s
      = 3000 rpm
        Mean motor speed over the cycle, dwell included (the travel's motor turns per cycle time)
  [50] P_rated = T_rated * n_rated
      = 2 N·m × 3000 rpm
      = 0.62832 kW
        Rated (nameplate) shaft power of the candidate motor: its rated torque times its rated speed
  [51] P_rms = omega_pk * sqrt((t_acc * (2 / 3) * (T_load^2 + T_acc^2) + T_load^2 * t_const) / t_cycle)
      = 942.48 rad/s × sqrt((0.16667 s × 2 / 3 × ((0.08671 N·m)^2 + (2.4922 N·m)^2) + (0.08671 N·m)^2 × 0.16667 s) / 1 s)
      = 0.78414 kW
        RMS mechanical power over the cycle (thermal-equivalent continuous power)
  [52] T_rms = sqrt((T_pk^2 * t_acc + T_load^2 * t_const + T_dec^2 * t_acc + T_hold^2 * t_dwell) / t_cycle)
      = sqrt(((2.5789 N·m)^2 × 0.16667 s + (0.08671 N·m)^2 × 0.16667 s + (-2.4055 N·m)^2 × 0.16667 s + (0 N·m)^2 × 0.5 s) / 1 s)
      = 1.4402 N·m
        RMS torque over the cycle (thermal), the dwell at the holding torque
  [53] J_ratio = (J_refl + J_mech) / J_motor
      = (0.00014072 kg·m² + 0.0001 kg·m²) / 0.0002 kg·m²
      = 1.2036
        Inertia ratio (load : motor)
  [54] T_pk_sf = SF * max(abs(T_pk), abs(T_dec))
      = 1.25 × max(abs(2.5789 N·m), abs(-2.4055 N·m))
      = 3.2237 N·m
        Peak torque with the safety factor, on the larger of the accelerating and the braking torque
  [55] T_rms_sf = SF * T_rms
      = 1.25 × 1.4402 N·m
      = 1.8002 N·m
        RMS torque with the safety factor
  [56] u_peak = SF * max(abs(T_pk), abs(T_dec)) / T_peak
      = 1.25 × max(abs(2.5789 N·m), abs(-2.4055 N·m)) / 6 N·m
      = 0.53728
        Peak torque utilisation with safety factor, on the larger of the accelerating and the braking torque
  [57] u_rms = SF * T_rms / T_rated
      = 1.25 × 1.4402 N·m / 2 N·m
      = 0.90012
        Continuous torque utilisation with safety factor
  [58] u_speed = n_pk / n_max
      = 9000 rpm / 10000 rpm
      = 0.9
        Speed utilisation
  [59] duty = T_rms / T_rated
      = 1.4402 N·m / 2 N·m
      = 0.7201
        Thermal duty (without margin)

7. Applicability
  WARNING  records: tabulated values not taken from a reference record are J_motor, T_rated, T_peak, n_rated, n_max (Candidate motor rating). Enter each as one so its source, edition and licence travel with it.  [record]
  WARNING  n_pk: the peak speed is 90 % of n_max, and T_peak is compared as the stall peak torque. A servo's peak torque falls toward its top speed, so check its torque-speed curve at n_pk.  [peak-at-speed]
  WARNING  T_dec: the motor brakes during deceleration (negative torque). The drive must absorb the regenerated energy.  [overhauling]
