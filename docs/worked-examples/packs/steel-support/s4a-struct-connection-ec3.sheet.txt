1. SCOPE AND METHOD
The design resistances of one bolt in a plate (shear, bearing, tension, punching, combined shear and tension), an optional block-tearing check of the bolt group, the spacing limits, and a fillet weld by the simplified and the directional method, each against its design force.
Bolt strengths: f_ub = class × 100 MPa; A_s = π/4·((d₂ + d₃)/2)², d₂ = d − 0.6495P, d₃ = d − 1.2269P Shear (cl. 3.6, Table 3.4): F_v,Rd = α_v·f_ub·A·n_s/γ_M2; α_v = 0.6 (4.6, 5.6, 8.8 or shank in the plane), 0.5 (4.8, 5.8, 6.8, 10.9 with threads in the plane) Bolt bearing resistance: F_b,Rd = k₁·α_b·f_u·d·t/γ_M2; α_b = min(α_d, f_ub/f_u, 1), α_d = e₁/3d₀ (end) or p₁/3d₀ − 1/4 (inner); k₁ = min(2.8e₂/d₀ − 1.7, 1.4p₂/d₀ − 1.7, 2.5) Bolt tension resistance: F_t,Rd = k₂·f_ub·A_s/γ_M2, k₂ = 0.9; punching B_p,Rd = 0.6π·d_m·t·f_u/γ_M2, d_m = (s + e)/2 from the across-flats s and the across-corners e of the smaller of head and nut, or d_m = s when e is not entered (conservative); combined F_v/F_v,Rd + F_t/(1.4F_t,Rd) ≤ 1 Block tearing (cl. 3.10.2): V_eff,1,Rd = f_u·A_nt/γ_M2 + f_y·A_nv/(√3·γ_M0) Weld, simplified (cl. 4.5.3.3): f_vw,d = f_u/(√3·β_w·γ_M2), F_w,Rd = f_vw,d·a; directional (cl. 4.5.3.2): √(σ⊥² + 3(τ⊥² + τ∥²)) ≤ f_u/(β_w·γ_M2), σ⊥ ≤ 0.9f_u/γ_M2
  Ref: EN 1993-1-8:2005 cl. 3.5, Table 3.3 — Positioning of holes for bolts
  Ref: EN 1993-1-8:2005 cl. 3.6.1, Table 3.4 — Design resistance of individual fasteners
  Ref: EN 1993-1-8:2005 cl. 3.10.2 — Block tearing
  Ref: EN 1993-1-8:2005 cl. 4.5.3.2, 4.5.3.3, Table 4.1 — Fillet welds: directional and simplified methods; correlation factor
  Ref: ISO 898-1:2013 cl. 9.1 — Nominal stress area (formula)

3. ASSUMPTIONS
  A1. Static loading; category A (bearing type) shear and category D (non-preloaded) tension; no slip-resistant joints or moment end plates. (Scope of S4.)
  A2. Bearing is taken at the worst of an end bolt and an inner bolt, and at an edge bolt across the load (k₁ with e₂ and p₂). (Conservative for every bolt in the group.)
  A3. Spacing minima (Table 3.3) and γ_M factors are entered from a National Annex record; the values shown default to EN 1993-1-8 recommended. (A small set of factors only; no table from a standard is shipped.)
  A4. Group forces come from M3 and weld forces per length from M6 by link. (Group forces and weld forces are linked from the bolt-group and weld-group calculations.)
  A5. n_s (Shear planes) is taken as 1. (Sheet default value; no project figure given.)
  A6. threads (Threads in the shear plane) is taken as yes. (Sheet default value; no project figure given.)
  A7. f_y (Plate yield strength) is taken as 275 MPa. (Sheet default value; no project figure given.)
  A8. f_u (Plate ultimate strength) is taken as 410 MPa. (Sheet default value; no project figure given.)
  A9. k_e1 (Minimum e₁/d₀) is taken as 1.2. (Sheet default value; no project figure given.)
  A10. k_e2 (Minimum e₂/d₀) is taken as 1.2. (Sheet default value; no project figure given.)
  A11. k_p1 (Minimum p₁/d₀) is taken as 2.2. (Sheet default value; no project figure given.)
  A12. k_p2 (Minimum p₂/d₀) is taken as 2.4. (Sheet default value; no project figure given.)
  A13. gamma_M2 (γ_M2) is taken as 1.25. (Sheet default value; no project figure given.)
  A14. gamma_M0 (γ_M0) is taken as 1. (Sheet default value; no project figure given.)

  [26] alpha_b = min(α_d, f_ub/f_u, 1), α_d = min(e₁/3d₀, p₁/3d₀ − 1/4)    « EN 1993-1-8 Table 3.4
      = min(0.60606, 2.0227, 1.9512, 1)

  [27] k_1 = min(2.8e₂/d₀ − 1.7, 1.4p₂/d₀ − 1.7, 2.5)    « EN 1993-1-8 Table 3.4
      = e₂ = 40, p₂ = 120, d₀ = 22
      = 2.5
        Bearing factor k₁
  [28] F_b_Rd = k₁·α_b·f_u·d·t/γ_M2    « EN 1993-1-8 Table 3.4

  [29] F_t_Rd = k₂·f_ub·A_s/γ_M2, k₂ = 0.9    « EN 1993-1-8 Table 3.4

  [30] B_p_Rd = 0.6π·d_m·t·f_u/γ_M2, d_m = s (e not entered)    « EN 1993-1-8 Table 3.4
      = 0.6π × 30 × 20 × 410 / 1.25
      = 370.96 kN
        Punching shear resistance
  [31] u_v = F_v_Ed / F_v_Rd
      = 4.7 kN / 94.001 kN
      = 0.049999
        Shear utilisation
  [32] u_b = F_v_Ed / F_b_Rd
      = 4.7 kN / 198.79 kN
      = 0.023643
        Bearing utilisation
  [33] u_t = F_t_Ed / min(F_t_Rd, B_p_Rd)
      = 47 kN / min(141 kN, 370.96 kN)
      = 0.33333
        Tension utilisation (tension or punching)
  [34] u_vt = F_v_Ed / F_v_Rd + F_t_Ed / (1.4 * F_t_Rd)    « EN 1993-1-8 Table 3.4
      = 4.7 kN / 94.001 kN + 47 kN / (1.4 × 141 kN)
      = 0.28809
        Combined shear and tension
  [38] V_eff_Rd = f_u * A_nt / gamma_M2 + f_y * A_nv / (sqrt(3) * gamma_M0)    « EN 1993-1-8 cl. 3.10.2
      = 410 MPa × 1200 mm² / 1.25 + 275 MPa × 2400 mm² / (sqrt(3) × 1)
      = 774.65 kN
        Block tearing resistance (concentric)
  [39] u_block = V_Ed / V_eff_Rd
      = 28.2 kN / 774.65 kN
      = 0.036403
        Block tearing utilisation
