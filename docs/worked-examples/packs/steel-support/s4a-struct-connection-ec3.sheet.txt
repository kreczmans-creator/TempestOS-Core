1. Scope and method
Calculates the design resistance of one bolt in a plate, block tearing of the bolt group, the spacing limits, and a fillet weld by the simplified and directional methods, each against its design force. Loading is static.
Bolt strengths: f_ub = class × 100 MPa; A_s = π/4·((d₂ + d₃)/2)², d₂ = d − 0.6495P, d₃ = d − 1.2269P Shear (cl. 3.6, Table 3.4): F_v,Rd = α_v·f_ub·A·n_s/γ_M2; α_v = 0.6 (4.6, 5.6, 8.8 or shank in the plane), 0.5 (4.8, 5.8, 6.8, 10.9 with threads in the plane) Bolt bearing resistance: F_b,Rd = k_h·min(k₁·α_b·f_u·d·t/γ_M2, [single lap, one bolt row: 1.5·f_u·d·t/γ_M2]); α_b = min(α_d, f_ub/f_u, 1), α_d = e₁/3d₀ (end) or p₁/3d₀ − 1/4 (inner); k₁ = min(2.8e₂/d₀ − 1.7, 1.4p₂/d₀ − 1.7, 2.5); k_h = 1 (normal holes), 0.8 (oversize), 0.6 (slot across the load) Bolt tension resistance: F_t,Rd = k₂·f_ub·A_s/γ_M2, k₂ = 0.9; punching B_p,Rd = 0.6π·d_m·t·f_u/γ_M2, d_m = (s + e)/2 from the across-flats s and the across-corners e of the smaller of head and nut, or d_m = s when e is not entered (conservative); combined F_v/F_v,Rd + F_t/(1.4F_t,Rd) ≤ 1 Block tearing (cl. 3.10.2): V_eff,1,Rd = f_u·A_nt/γ_M2 + f_y·A_nv/(√3·γ_M0) for a group loaded concentrically; V_eff,2,Rd = 0.5·f_u·A_nt/γ_M2 + f_y·A_nv/(√3·γ_M0) for an eccentrically loaded group Weld, simplified (cl. 4.5.3.3): f_vw,d = f_u/(√3·β_w·γ_M2), F_w,Rd = f_vw,d·a; directional (cl. 4.5.3.2): √(σ⊥² + 3(τ⊥² + τ∥²)) ≤ f_u/(β_w·γ_M2), σ⊥ ≤ 0.9f_u/γ_M2

3. Assumptions
  A1. Loading is static. (Scope of this sheet.)
  A2. Bolts are category A in shear (bearing type) and category D in tension (non-preloaded). (Scope of this sheet.)
  A3. The joint has no slip-resistant bolts and no moment end plates. (Scope of this sheet.)
  A4. Bearing is taken at the worst of an end bolt and an inner bolt. (Conservative for every bolt in the group.)
  A5. Bearing across the load is taken at an edge bolt, with k₁ from e₂ and p₂. (Conservative for every bolt in the group.)
  A6. Oversize holes reduce the bearing resistance by 0.8, and a slot across the load by 0.6. (BS EN 1993-1-8:2005 cl. 3.6.1, Table 3.4.)
  A7. A hole above the normal clearance, with the hole type left at normal, is treated as oversize. (BS EN 1993-1-8:2005 cl. 3.6.1, Table 3.4.)
  A8. The single-lap cap on the bearing resistance applies only when the single-lap switch is on. (BS EN 1993-1-8:2005 cl. 3.6.1; a warning says when it would bind.)
  A9. Spacing minima and γ_M factors are entered from a National Annex record. (A small set of factors only; no table from a standard is shipped.)
  A10. The defaults for the spacing minima and γ_M factors are the recommended values of BS EN 1993-1-8. (A small set of factors only; no table from a standard is shipped.)
  A11. Group forces and weld forces per length come from the bolt group and weld group sheets by link. (Linked from the bolt-group and weld-group calculations.)
  A12. hole_type (Hole type: oversize holes reduce the bearing resistance by 0.8, a slot across the load by 0.6 (a d₀ above the normal clearance is treated as oversize)) is taken as Normal clearance. (Sheet default value; no project figure given.)
  A13. block_load (Block tearing loading: concentric (V_eff,1) or eccentric (V_eff,2, the tension term halved)) is taken as Concentric loading (V_eff,1). (Sheet default value; no project figure given.)
  A14. single_lap (Single-lap joint with only one bolt row (limits the bearing resistance to 1.5·f_u·d·t/γ_M2, cl. 3.6.1)) is taken as no. (Sheet default value; no project figure given.)
  A15. threads (Threads in the shear plane) is taken as yes. (Sheet default value; no project figure given.)
  A16. n_s (Shear planes) is taken as 1. (Sheet default value; no project figure given.)
  A17. f_y (Plate yield strength) is taken as 275 MPa. (Sheet default value; no project figure given.)
  A18. f_u (Plate ultimate tensile strength) is taken as 410 MPa. (Sheet default value; no project figure given.)
  A19. gamma_M2 (Partial factor for bolt and weld resistance) is taken as 1.25. (Sheet default value; no project figure given.)
  A20. gamma_M0 (Partial factor for cross-section resistance) is taken as 1. (Sheet default value; no project figure given.)
  A21. k_e1 (Minimum e₁/d₀) is taken as 1.2. (Sheet default value; no project figure given.)
  A22. k_e2 (Minimum e₂/d₀) is taken as 1.2. (Sheet default value; no project figure given.)
  A23. k_p1 (Minimum p₁/d₀) is taken as 2.2. (Sheet default value; no project figure given.)
  A24. k_p2 (Minimum p₂/d₀) is taken as 2.4. (Sheet default value; no project figure given.)
  A25. Bearing is taken on the thinner ply, 11 mm, with this sheet's f_u, edge distances and spacings. (t_p = 20 mm and t_2 = 11 mm; where the other ply differs, run the sheet for it as well (BS EN 1993-1-8 cl. 3.6.1, Table 3.4).)

4. Working
  [21] f_ub = class first figure × 100    « EN 1993-1-8 Table 3.1
      = class 8.8
      = 800 MPa
        Bolt ultimate tensile strength
  [22] f_yb = f_ub × second figure / 10    « EN 1993-1-8 Table 3.1
      = class 8.8
      = 640 MPa
        Bolt yield strength
  [23] A_s = π/4·((d₂ + d₃)/2)², d₂ = d − 0.6495P, d₃ = d − 1.2269P    « ISO 898-1 cl. 9.1
      = d = 20, P = 2.5 mm
      = 244.79 mm²
        Tensile stress area
  [24] d_0 = d + 2 (≤ M24), d + 3 (≥ M27) unless entered
      = 22 mm
      = 22 mm
        Hole diameter
  [25] alpha_v = α_v (threads in the shear plane)    « EN 1993-1-8 Table 3.4
      = class 8.8
      = 0.6
        Shear factor
  [26] F_v_Rd = α_v·f_ub·A·n_s/γ_M2    « EN 1993-1-8 Table 3.4
      = 0.6 × 800 × 244.79 × 1 / 1.25
      = 94.001 kN
        Shear resistance per bolt
  [27] alpha_b = min(α_d, f_ub/f_u, 1), α_d = min(e₁/3d₀, p₁/3d₀ − 1/4)    « EN 1993-1-8 Table 3.4
      = min(0.60606, 2.0227, 1.9512, 1)
      = 0.60606
        Bearing factor α_b
  [28] k_1 = min(2.8e₂/d₀ − 1.7, 1.4p₂/d₀ − 1.7, 2.5)    « EN 1993-1-8 Table 3.4
      = e₂ = 40, p₂ = 120, d₀ = 22
      = 2.5
        Bearing factor k₁
  [31] F_b_Rd = k₁·α_b·f_u·d·t/γ_M2    « EN 1993-1-8 cl. 3.6.1, Table 3.4
      = 2.5 × 0.60606 × 410 × 20 × 11 / 1.25
      = 109.33 kN
        Bearing resistance per bolt
  [32] F_t_Rd = k₂·f_ub·A_s/γ_M2, k₂ = 0.9    « EN 1993-1-8 Table 3.4
      = 0.9 × 800 × 244.79 / 1.25
      = 141 kN
        Tension resistance per bolt
  [33] B_p_Rd = 0.6π·d_m·t·f_u/γ_M2, d_m = s (e not entered)    « EN 1993-1-8 Table 3.4
      = 0.6π × 30 × 20 × 410 / 1.25
      = 370.96 kN
        Punching shear resistance
  [34] u_v = F_v_Ed / F_v_Rd
      = 4.7 kN / 94.001 kN
      = 0.049999
        Shear utilisation
  [35] u_b = F_v_Ed / F_b_Rd
      = 4.7 kN / 109.33 kN
      = 0.042988
        Bearing utilisation
  [36] u_t = F_t_Ed / min(F_t_Rd, B_p_Rd)
      = 47 kN / min(141 kN, 370.96 kN)
      = 0.33333
        Tension utilisation (tension or punching)
  [37] u_vt = F_v_Ed / F_v_Rd + F_t_Ed / (1.4 * F_t_Rd)    « EN 1993-1-8 Table 3.4
      = 4.7 kN / 94.001 kN + 47 kN / (1.4 × 141 kN)
      = 0.28809
        Combined shear and tension
  [42] V_eff_Rd = f_u * A_nt / gamma_M2 + f_y * A_nv / (sqrt(3) * gamma_M0)    « EN 1993-1-8 cl. 3.10.2
      = 410 MPa × 1200 mm² / 1.25 + 275 MPa × 2400 mm² / (sqrt(3) × 1)
      = 774.65 kN
        Block tearing resistance V_eff,1 (concentric loading)
  [43] u_block = V_Ed / V_eff_Rd
      = 28.2 kN / 774.65 kN
      = 0.036403
        Block tearing utilisation
  [45] u_limit = limit
      = the utilisation limit
      = 1
        Utilisation limit
  [46] F_t_lim = min(F_t_Rd, B_p_Rd)
      = min(141 kN, 370.96 kN)
      = 141 kN
        Governing tension or punching resistance
