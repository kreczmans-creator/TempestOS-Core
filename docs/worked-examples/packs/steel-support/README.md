# Calc pack — Steel support (`pack.steel-support`)

**Chain.** Load combinations (`struct.load-combinations`) → Support frame (`struct.frame-2d`) → Column check (`struct.en1993-member`) → Arm connection and bolts (`struct.connection-ec3`) → Column base plate (`struct.base-plate`).

**Purpose.** Combines the actions on an equipment support, analyses the steel frame, checks the column, designs the bolted connection and the column base plate, and files the anchorage design done elsewhere as Evidence.

The equipment's dead and maintenance loads are combined (EN 1990); the ULS vertical effect is a cell of the frame's load table; the frame's column forces check the column, its arm shear loads the bolted connection and its base reactions are the base plate's actions; the connection's bolt values are the holding-down bolt data. **The anchorage (concrete and anchor design) is done in Hilti PROFIS: the file attached to the base-plate step is a PLACEHOLDER, not a PROFIS report, to be replaced by the engineer's own report before the pack is used.**

**Issue.** Project “Equipment support ES-4”, pack “Equipment support steelwork calc pack”, checked once as a bundle and issued under issue reference **`STR-SUP-001`** to Client Co in one transaction. After issue every step is read-only and carries that reference. Checked against SPEC-STR-09 and DRG-STR-310 to 315 rev B.

## Inputs and provenance

Every input of every step carries a provenance on the issued sheet: the figures chosen for this example cite an (invented) specification or drawing, an input left at the sheet's default is recorded as an assumption, and a linked input names the calculation and output it comes from. Project, drawing, specification and issue references are illustrative; they are not real documents.

The base-plate step cites `PROFIS-BP1-PLACEHOLDER.txt`, filed against its Evidence; that file only says it is a placeholder.
