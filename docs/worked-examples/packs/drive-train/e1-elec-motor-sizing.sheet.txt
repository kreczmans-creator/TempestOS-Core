1. SCOPE AND METHOD
Torque, speed and power a motor needs to move a load through a mechanism on a point-to-point cycle: the load reflected to the motor shaft, the acceleration from the motion profile, peak torque during acceleration, RMS torque over the cycle (thermal duty), peak speed, inertia ratio, and a check of a candidate motor's rated and peak torque and speed with a safety margin. A rotary load that runs continuously (a pump, a fan) is sized instead from its steady torque and speed and a run-up time.
Linear mechanisms: k = metres per motor radian (screw p/(2π i); belt D/(2 i); rack D_p/(2 i)); J_refl = m k²/η; T_load = F k/η with F = m g (sin θ + μ cos θ) + F_p. Rotary: J_refl = J_L/(i² η), T_load = T_L/(i η). Trapezoidal 1/3–1/3–1/3 (adjustable): v_pk = s/(t_move − t_acc), a = v_pk/t_acc; S-curve: sine acceleration with a_pk = (π/2) a_trap and the same v_pk. T_acc = J_total α; T_pk = T_acc + T_load; T_rms = √(Σ T_i² t_i / t_cycle) including the dwell. Continuous rotary duty: ω = 2π n_L i/60; T_load = T_L/(i η); T_rms = T_load; T_pk = J_total ω/t_start + T_load (full load during the run-up, conservative); n_pk = n_L i; P_cont = T_load ω.
  Ref: Hughes & Drury, Electric Motors and Drives Ch. on motor and drive selection — Load torque, inertia referred to the motor, duty cycles
  Ref: Manufacturer servo-sizing guides (Kollmorgen, Parker) — Reflected inertia, RMS torque, inertia ratio practice

3. ASSUMPTIONS
  A1. Rigid transmission; the mechanism efficiency applies to the driving direction and is also used in the deceleration phase (conservative for peak, slightly pessimistic for RMS). (Servo-sizing practice.)
  A2. The friction force is Coulomb friction on the moved mass; viscous and breakaway friction are not modelled unless included in F_p. (Load model.)
  A3. Continuous duty: the load torque is constant at the stated speed and the motor accelerates the whole inertia linearly to speed in t_start while carrying the full load torque (conservative); the move distance, move time, acceleration fraction, dwell and profile are ignored. (Run-up idealisation for pumps and fans.)
  A4. The S-curve profile has sine-shaped acceleration over the same acceleration time, so its peak acceleration is π/2 times the trapezoidal value. (Jerk-limited profile idealisation.)
  A5. p_screw (Screw lead (per revolution of the screw)) is taken as 10 mm. (Sheet default value; no project figure given.)
  A6. m (Moved mass (linear mechanisms)) is taken as 50 kg. (Sheet default value; no project figure given.)
  A7. mu (Friction coefficient (guide / bearing)) is taken as 0.1. (Sheet default value; no project figure given.)
  A8. theta (Incline from horizontal (+ moving uphill)) is taken as 0 deg. (Sheet default value; no project figure given.)
  A9. F_p (Process force opposing the move (linear)) is taken as 0 N. (Sheet default value; no project figure given.)
  A10. profile (Motion profile) is taken as trapezoidal. (Sheet default value; no project figure given.)
  A11. s (Move distance (linear: m; rotary: output revolutions)) is taken as 0.5. (Sheet default value; no project figure given.)
  A12. t_move (Move time) is taken as 0.5 s. (Sheet default value; no project figure given.)
  A13. f_acc (Acceleration (and deceleration) fraction of the move time) is taken as 0.333333. (Sheet default value; no project figure given.)
  A14. t_dwell (Dwell between moves) is taken as 0.5 s. (Sheet default value; no project figure given.)
  A15. SF (Safety margin on torque) is taken as 1.25. (Sheet default value; no project figure given.)
  A16. J_ratio_max (Inertia ratio limit (load : motor), warning) is taken as 10. (Sheet default value; no project figure given.)

4. WORKING
  [19] k = 1 / i
      = 1 / 12.5
      = 0.08
        Output radians per motor radian
  [20] T_load = T_L / (i * eta)
      = 1800 N·m / (12.5 × 0.95)
      = 151.58 N·m
        Load torque at the motor shaft (constant)
  [21] J_refl = J_L / (i^2 * eta)
      = 4 kg·m² / (12.5^2 × 0.95)
      = 0.026947 kg·m²
        Load inertia reflected to the motor shaft
  [22] omega_pk = n_L * i
      = 120 rpm × 12.5
      = 157.08 rad/s
        Motor speed, n_L · i
  [23] J_total = J_motor + J_mech + J_refl
      = 0.12 kg·m² + 0.002 kg·m² + 0.026947 kg·m²
      = 0.14895 kg·m²
        Total inertia at the motor shaft
  [24] alpha_pk = omega_pk / t_start
      = 157.08 rad/s / 3 s
      = 52.36 rad/s²
        Run-up angular acceleration (to speed in t_start)
  [25] T_acc = J_total * alpha_pk
      = 0.14895 kg·m² × 52.36 rad/s²
      = 7.7989 N·m
        Run-up (acceleration) torque
  [26] T_pk = T_acc + T_load
      = 7.7989 N·m + 151.58 N·m
      = 159.38 N·m
        Peak torque: run-up carrying the full load (conservative)
  [27] T_rms = T_load
      = 151.58 N·m
      = 151.58 N·m
        RMS torque: continuous running at the load torque
  [28] n_pk = omega_pk
      = 157.08 rad/s
      = 1500 rpm
        Motor speed
  [29] P_cont = T_load * omega_pk
      = 151.58 N·m × 157.08 rad/s
      = 23810 W
        Continuous shaft power at the motor
  [30] P_pk = T_pk * omega_pk
      = 159.38 N·m × 157.08 rad/s
      = 25.035 kW
        Peak mechanical power (end of the run-up)
  [31] J_ratio = (J_refl + J_mech) / J_motor
      = (0.026947 kg·m² + 0.002 kg·m²) / 0.12 kg·m²
      = 0.24123
        Inertia ratio (load : motor)
  [32] u_peak = SF * T_pk / T_peak
      = 1.25 × 159.38 N·m / 400 N·m
      = 0.49806
        Peak torque utilisation with safety margin
  [33] u_rms = SF * T_rms / T_rated
      = 1.25 × 151.58 N·m / 200 N·m
      = 0.94737
        Continuous torque utilisation with safety margin
  [34] u_speed = n_pk / n_max
      = 1500 rpm / 3000 rpm
      = 0.5
        Speed utilisation
  [35] duty = T_rms / T_rated
      = 151.58 N·m / 200 N·m
      = 0.75789
        Thermal duty (without margin)
