# TempestOS v0.26.0 — test values for every worksheet calculator

Generated by `scripts/generate-test-values.py` from the 87 worked examples of the 54 worksheet templates (docs/worked-examples). Every value here is the one the build's automated tests check: the worked-example tests re-run each example and compare these outputs.

**How to use a set.** In the Desktop open Modules → Calculations → Worksheets and pick the template. Either import the example's `inputs.json` (Import inputs… on the worksheet form; the path is given) or type the inputs below. Run it. Each expected output must match to the digits shown. The governing check must read as stated. A table input lists its rows under it (for example `sizes[1]`).

Units are written as symbols (kN·m, m², °C, Ω), as the sheet prints them; the form's unit list spells the same unit kN*m, m^2, degC, ohm. `bar a` and `bar g` are absolute and gauge bar. A value marked `default` is the form's own default: leave it as it opens.
