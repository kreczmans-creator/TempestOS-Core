# TempestOS v0.8.0 — Work Packages

## Status

**In progress.** `feature/v0.8.0-engineering-workspace` was cut from
`main` at the `v0.7.0` tag, mirroring `v0.6.0`'s own "prepare next
branch and release documentation" precedent (`18e61d5`). `WP 8.0A`
(Engineering Workspace Architecture) is this release's own first Work
Package — an architecture and design phase only, no implementation —
following this project's own standing discipline (`FOUNDATION.md` §1:
architecture precedes implementation for anything non-trivial).

## Work Packages

| Work Package | Scope | Status |
|---|---|---|
| `WP 8.0A` | Engineering Workspace Architecture — workspace philosophy, user journeys, main window layout, navigation model, Project Explorer, engineering object hierarchy, docking strategy, view architecture, digital thread visualisation, state management, extensibility model, interaction patterns. Architecture and design only; no implementation. | In progress |

Further Work Packages (contract review, implementation) are not yet
scoped — each must pass through this project's own standing discipline

implementation" constraint.
