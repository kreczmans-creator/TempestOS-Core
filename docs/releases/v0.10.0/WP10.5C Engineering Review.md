## 4. Requirements' Own Undecorated Node — Independently Verified Correct, Not an Oversight

Confirmed directly: `IRequirement.Status` is `RequirementStatus`
(`Draft`/`Reviewed`/`Approved`/`Allocated`/`Verified`/`Satisfied`/`Obsolete`),
a closed set with no member corresponding cleanly to `LifecycleState`'s
own `Superseded`/`Archived`/`Cancelled`, and two members
(`Allocated`/`Verified`) with no `LifecycleState` equivalent at all. A
force-mapping would have to either drop information or invent a
correspondence not backed by either enum's own real semantics — the
Work Package's own decision to leave this node undecorated rather than
guess is engineering-sound, not a gap in effort.
