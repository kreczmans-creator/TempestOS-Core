# TempestOS v0.12.0 — Work Packages

## Status

**In progress.** `v0.12.0` — "Desktop Composition & Domain Vocabulary
Hardening" — branch `feature/v0.12.0-desktop-composition-domain-vocabulary-hardening`,
cut from `main` at `b203aef` (the `v0.11.0` merge commit's own successor
on `main`). This document is created now, per this project's own
established convention ("each release's own `WorkPackages.md` is
created when that release's branch is cut," `WP11.4B Release Process
Correction Report.md` §10), seeded from `WP11.0B Architecture Roadmap.md`
§3's own predicted `v0.12.0` table.

**`WP 12.3A`/`WP 12.3B`** were this release's own first completed Work
Packages — a directly-commissioned pair, not named in the roadmap's own
predicted `12.0`–`12.2` slots, the identical pattern `WP 11.3A`/`WP
11.3B` and `WP 11.4A`/`WP 11.4B` each already established for
`v0.11.0`. **`WP 12.0A`/`WP 12.0B`** are the roadmap's own first
*predicted* `v0.12.0` Work Package pair, now both complete — `WP 12.0A`
designed `ADR-0103`/`Desktop Composition Architecture.md`; `WP 12.0B`
implements it exactly, closing Finding `A-1` in full: `MainWindow`
(1,556 → 544 lines) into nine `Tempest.Desktop.Composition`
collaborators, `EngineeringCockpit` (1,398 → 575 lines) into six
per-discipline collaborators. **`WP 12.4A`** (Desktop Command & Event
Wiring Architecture) is a second directly-commissioned Work Package,
following the identical `WP 12.3A`/`WP 12.3B` precedent — reviews the
Desktop layer's own command/event wiring after `WP 12.0B`'s
decomposition and produces `ADR-0104` (Desktop cross-collaborator
communication: direct delegates or typed callback interfaces only,
never a Desktop-local Mediator/Command Dispatcher/Event Dispatcher);
architecture only, on its own branch
(`feature/v0.12.0-desktop-command-event-wiring`), not merged into this
one. **Disclosed naming note**: this Work Package's own scope was
initially proposed under the label `WP 12.1A` before being corrected —
`WP 12.1A` already names the roadmap-predicted "Classification &
Relationship Vocabulary Safety Net Architecture" item, below, unrelated
and untouched by this renumbering. **`WP 12.4B`** (Desktop Command &
Event Wiring Implementation), on the same branch, realises `ADR-0104`
exactly: consolidates `RibbonObjectActionHandlers`'s own 16 duplicated
report-then-refresh tails into one local function, and closes `WP
12.0B`'s own architecture review Finding 5 in both `UndoRedoCoordinator`
and `WorkspaceViewCoordinator` (a two-phase-constructed `CockpitView`
object reference replaced with a plain `Action` delegate). `WP 12.1A`,
`12.1B`, `12.2A`, and `12.9.0` remain **Not started**.
