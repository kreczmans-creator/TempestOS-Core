# Archive — 2026-09-08 Governance Reset

This directory holds the Work Package retrospectives, review-board dispositions, status reports, readiness reviews, completion certifications, governance registers and superseded architecture documents that TempestOS accumulated from `v0.4.0` through `v0.16.0`, moved here as one act under `WP 17.0B` ("Governance reset", `docs/releases/v1.0.0/WorkPackages.md`) because the process of producing and re-deriving them had grown to cost more than the product they were meant to protect. Nothing here was deleted: every file was moved with `git mv`, so its full history — every prior edit, every author, every commit it was part of — remains intact and reachable by `git log --follow` on its new path, and by checking out any commit before this reset for its old one. `BACKLOG.md` at the repository root carries forward, in a thirty-line cap, whatever technical debt this reset judged a user could still notice; the frozen `Technical Debt Register.md` under `governance/Quality/` here is the full historical record that triage was drawn from.
