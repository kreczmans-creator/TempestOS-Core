# WP 11.5A — Governance Currency & Documentation Integrity

## 1. Introduction

`WP 11.5A` (`df46ab7`, merged `a417ade`) audited the repository's
governance documentation against actual current state, commissioned as a
`v0.11.0` follow-up but executed and merged after `v0.14.0`, inside the
same commit range `WP 15.1A` later formalised as `v0.15.0`. The full
account — before/after audit, every correction, Verified/Inferred/Unknown
classification — is its own dedicated report, not repeated here: `docs/
releases/v0.11.0/WP11.5A Governance Currency & Documentation Integrity.md`.
This article exists because Engineering Governance §6 requires one per
Work Package regardless of subject matter — a governance Work Package is
not exempt from the Academy obligation it itself partly audits.

## 2. Purpose

Verify whether `WP 11.2A`'s own disclosed governance gaps (Academy Index
links stopping at `WP 7.3A`; untracked-directory references) still exist,
and correct whatever genuine drift the audit actually found.

## 3. Background

Commissioned by name, and by path (`docs/releases/v0.11.0/`), as though
`v0.11.0` had an open next slot. It does not — `v0.11.0` closed with
`WP 11.4B`. The premise was checked against the repository, the
discrepancy was put to the commissioning party directly, and the
instruction received back was: audit, disclose, fix only what is
genuinely still drifted.

## 4. The Problem

`WP 11.2A`'s own two named gaps were found already remediated three
releases earlier (`WP 12.9.1`/`WP 12.9.2`, `v0.12.0`) — no redundant fix
was fabricated. The audit found different, genuinely current drift
instead: stale summary counts in `Governance Index.md`; five stale
directory counts and four missing release rows in `Documentation
Register.md`; a stale `ADR-0095` "permanently reserved" cross-reference;
and `main`'s own undisclosed 18-commit divergence from the `v0.14.0` tag.

## 5. The Design

Corrected the counts and cross-references found stale; added the missing
Documentation Register rows; disclosed (not fixed) `main`'s divergence in
`PROJECT_STATUS.md` as the next release-preparation Work Package's own
starting point. `v0.11.0`'s own closed `WorkPackages.md` was deliberately
left unmodified.

## 6. Alternatives Considered

Fabricating an eleventh `v0.11.0` Work Package row to match the
commissioning brief's own literal framing — rejected: `v0.11.0` is
closed, tagged, and published; reopening its own accounting to record
work actually done three releases and one undocumented programme later
would misrepresent that release's own history.

## 7. Why This Solution Was Chosen

Auditing before fixing anything avoids the two failure modes a
governance Work Package is most exposed to: fabricating remediation for
an already-closed gap, and silently absorbing a different register's own
disclosed, out-of-scope debt.

## 8. Architectural Principles

No ADR, architecture, or production/test file was touched — a governance
documentation pass changes what the repository *says* about itself, not
what it *is*.

## 9. Benefits

`Governance Index.md` and `Documentation Register.md` are both current
again; `main`'s divergence from its own last tag is now a disclosed,
named fact rather than a silent one — directly enabling `WP 15.1A`.

## 10. Trade-offs

Two findings were disclosed and deliberately not fixed: `v0.11.0`'s own
missing Academy retrospectives (already known via `WP-Z3` §12), and
`Architecture Document Register.md`'s own separately-disclosed stale ADR
count. Both remain open after this Work Package.

## 11. Common Mistakes

**Complying literally with a commissioning brief's premise without
checking it against the repository first.** The brief named a specific
Work Package number and release folder that, checked directly, no longer
matched reality.

## 12. Future Evolution

This retrospective was written retroactively by `WP 15.1A`, at the same
time as `WP 15.0A`–`D`'s — `WP 11.5A` itself, like every Work Package in
this commit range, shipped without one. `WP 15.1A`'s own Release
Preparation Report names the recommended next work; §4's finding directly
became this Work Package's own opening question.

## 13. Key Takeaways

- Audit before fixing: a commissioning brief's premise can be
  out of date even when the request is specific and confident.
- Disclosing a finding as out-of-scope is a legitimate, complete
  resolution when backfilling it is itself a separate undertaking.
- A governance Work Package still owes the Academy its own retrospective.
