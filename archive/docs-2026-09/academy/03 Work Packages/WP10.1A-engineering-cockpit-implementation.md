# WP 10.1A — Engineering Cockpit Implementation

## 1. Introduction

`WP 10.1A` is Programme 10's own third Work Package, and `v0.10.0`'s
second implementation Work Package — the complete graphical Engineering
Cockpit, built over `Tempest.Desktop` (`WP 10.0B`), auditing and
upgrading every disclosed Cockpit placeholder this project has carried
since `WP 8.1C`.

## 2. Purpose

To realise `WP10.0A UX Architecture Document.md`'s own Cockpit design
as real, running, tested code — replacing every placeholder with live
data wherever the platform already has it, and disclosing honestly
where it does not.

## Architectural Debt Assessment

One significant, genuine, pre-existing finding: four `Tempest.Samples`
modules (`engineeringdomain`, `materials`, `requirements`,
`requirementsworkspace`) each fail their own `InitialiseAsync` against
their own literal Id — confirmed reproducible, confirmed not caused by
this Work Package's own code, root cause not fully diagnosed within
this Work Package's own Cockpit-focused scope. Registered as a new,
Open Technical Debt item (`WP10.1A Technical Debt Review.md` §1),
recommended for a dedicated future Runtime Host/Module Discovery Work
Package. `TD-26` reconfirmed Open a third time; its own `Tempest.Desktop`
mitigation strengthened from a narrow, six-item proxy to the Runtime
Host's own authoritative `HostState.Running` signal.

## Observations

- **Reading real data honestly is itself a test.** Three of this Work
  Package's own six upgraded Cockpit members would have shown populated
  sample data if the platform's own sample-seeding modules were
  working correctly — building the real read, and testing it against
  the real platform, is what surfaced that they are not.
- **A disclosed placeholder's own documentation is a reliable source of
  truth for what to check, not what to assume.** Every one of the six
  upgraded members' own "why this is still placeholder" comment named,
  precisely, the exact condition to re-verify — and in four of six
  cases (Decision, Blocked Items via Verification, Risk, Milestone),
  the underlying Domain data had already existed, uncounted, for at
  least one prior release.
- **A stronger platform signal, adopted the moment a real gap
  demonstrates the weaker one's limits**, is the correct response —
  not a larger, ad hoc list of special cases.
