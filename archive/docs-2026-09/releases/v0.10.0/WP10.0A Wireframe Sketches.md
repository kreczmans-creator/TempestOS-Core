# WP 10.0A — Wireframe Sketches

## Purpose

ASCII-art wireframes for the highest-value screens named in `WP10.0A
Screen Catalogue.md`. Intent, not implementation — no pixel
measurement, colour value, or font is fixed here; full visual detail:
`WP10.0A Visual Design System.md`. Mirrors and extends `WP8.0C
Wireframe Sketches.md`'s own precedent, now for a graphical desktop
canvas rather than a terminal grid.

## 3. Object Editor with Dirty State

```
┌───────────────────────────────────────────┐
│ Spar Web Plate — Part *  ×                │  ← "*" = dirty-state indicator
│───────────────────────────────────────────│
│ Name:        [ Spar Web Plate (Rev C)    ]│  ← edited, not yet committed
│ Description: [ Machined aluminium web... ]│
│                                             │
│ Lifecycle:   ● InReview   [Change Status ▾]│
│                                             │
│                          [Discard] [Save]  │
└───────────────────────────────────────────┘
```

"Save" dispatches the existing `RenameMechanicalObjectCommand`/
`ReviseMechanicalObjectCommand`-shaped command via
`ICommandDispatcher` — the editor never writes directly (`WP10.0A UX
Architecture Document.md` §8).

## 4. Command Palette (Overlay)

```
┌──────────────────────────────────────────────────────┐
│  ⌘  approve                                       ✕  │
├──────────────────────────────────────────────────────┤
│  Requirements                                          │
│    Approve Requirement                    Ctrl+Alt+A   │
│  Calculations                                          │
│    Approve Calculation                                 │
│  Documents                                              │
│    Approve Document                                    │
│  Manufacturing                                          │
│    Release Manufacturing Operation   (alias: Approve)  │
└──────────────────────────────────────────────────────┘
```

Populated from `ICommandRegistry.GetDescriptors()`, filtered by fuzzy
match against the typed query and, where a selection exists, by
applicability to the selected object's own `Kind`/lifecycle state —
identical filtering rule as context menus (`WP10.0A Interaction
Specification.md` §4), applied to a global overlay instead of a
right-click menu.

## 5. Object Relationship View (Expanded Graph)

```
┌──────────────────────────────────────────────────────────┐
│ Object Relationship View — Spar Web Plate            [+] │
│────────────────────────────────────────────────────────── │
│                                                              │
│        REQ-0142 ●───references───▶ [Spar Web Plate]        │
│         Requirement                    ● (centre)          │
│              │                          │                   │
│         verifiedBy                 verifiedBy               │
│              ▼                          ▼                   │
│         Test-0091               Beam Bending Stress Calc     │
│          ● Fail                  ● basedOnCalculation ──▶    │
│                                     Bearing Load Capacity     │
│                                          (collapsed — click   │
│                                           to expand)          │
└──────────────────────────────────────────────────────────┘
```

Every node beyond the centre was added by an explicit expansion action
(`ADR-0093`) — the graph never pre-fetches beyond one hop from any
already-expanded node. Collapsing a node removes it and every edge that
depended only on it, discarding that branch's own presentation-local
state — no cached transitive graph persists anywhere.

## 6. Empty / Loading / Error States

```
Empty (Property Inspector, no selection):
┌───────────────────────────────┐
│  No selection.                 │
│  Select an object in Project   │
│  Explorer to inspect it.       │
└───────────────────────────────┘

Loading (Object Relationship View, read in flight):
┌───────────────────────────────┐
│  ⟳ Loading relationships…      │
└───────────────────────────────┘

Error (Read failure, permission-gated):
┌───────────────────────────────┐
│  ⚠ Could not load evidence.    │
│  You may not have permission   │
│  to view this relationship.    │
│                       [Retry]  │
└───────────────────────────────┘
```

Each state is scoped to the single panel that produced it — every
other region of the Workspace Shell (§2) remains fully functional
while any one panel shows an error, per `WP10.0A Screen Catalogue.md`
§19's own failure-isolation principle.
