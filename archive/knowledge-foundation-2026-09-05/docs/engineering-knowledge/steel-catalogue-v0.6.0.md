# Steel Catalogue v0.6.0

The steel family is now expanded from the original seed set into a broader engineering screening catalogue.

## Families represented

- low-carbon steels
- medium-carbon steels
- structural steels
- chromium-molybdenum steels
- nickel-chromium-molybdenum steels
- case-hardening steels
- bearing steels

## Important data rule

The catalogue's numeric values are **candidate reference values**. Steel properties vary materially with:

- product form
- section size
- heat treatment
- delivery condition
- hardness
- test direction
- test temperature

Therefore the catalogue must never expose a single value as universally valid where the underlying standard/source defines a range or condition.

## Legacy designations

EN8, EN19 and EN24 are retained because they are useful engineering/search terms, but legacy designation equivalence must be handled as a mapping with confidence and source evidence—not as an unconditional synonym.
