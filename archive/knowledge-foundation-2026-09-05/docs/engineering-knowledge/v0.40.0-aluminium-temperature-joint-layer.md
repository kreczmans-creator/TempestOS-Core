# v0.40.0 — Aluminium Temperature, Shear/Bearing and Joint Layer

This pass extends the aluminium foundation into the engineering behaviours that
become important once the library is used for actual design reasoning.

## Added

### Temperature
A controlled temperature-behaviour framework covering:

- strength
- modulus
- thermal conductivity
- thermal expansion
- specific heat
- electrical resistivity
- cryogenic/elevated-temperature evidence requirements

### Shear and bearing
A dedicated schema now distinguishes:

- shear yield
- shear ultimate
- bearing yield
- bearing ultimate
- alloy
- temper
- product form
- thickness
- orientation
- test standard
- source/evidence status

### Joints
A qualitative connection layer covers:

- bolted joints
- riveted joints
- welded joints
- adhesive bonds
- machined integral features
- cast components
- additive-manufactured components

### Fatigue and fracture
The previous frameworks have been refined into evidence-ready models with
explicit environmental, geometric, orientation, temperature and test
dimensions.

## Status

This is a **knowledge-model and evidence-architecture expansion**. It does not
create design allowables where authoritative evidence has not yet been
populated.

No aluminium record is approved for design use.
