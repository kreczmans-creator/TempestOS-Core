# Engineering Knowledge Foundation v1.7.0

## Steel evidence pass

This release establishes the operational sourcing structure for the 16-steel corpus.

### What is now in place

- normative/source registry for the principal steel standards already referenced by the catalogue;
- observation-level source-binding queue;
- steel evidence-depth plan;
- evidence-gate golden fixtures.

### Important boundary

This release does **not** claim that the existing numerical values are now verified. Source identification is not the same thing as source binding.

A property observation becomes reviewable only when its exact source locator and applicability are captured, including condition and, where relevant, product form, section/thickness, temperature and test method.

### Research priority

Close a small number of representative grades end-to-end first, then scale the same process across the catalogue. This gives TempestOS a repeatable evidence pipeline instead of a large unverified table.
