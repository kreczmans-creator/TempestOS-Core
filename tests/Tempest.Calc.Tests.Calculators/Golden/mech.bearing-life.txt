Title: Rolling bearing life (ISO 281)

1. SCOPE AND METHOD
The basic and modified rating life of a rolling bearing under a steady load or a duty cycle, at a chosen reliability, against a required life; and the static safety factor against a required value.
Equivalent load: P = F_r when F_a/F_r ≤ e_lim, else P = X·F_r + Y·F_a Duty cycle: P_eq = (Σ P_i^p·U_i / Σ U_i)^(1/p) Basic rating life: L_10 = (C/P)^p million revolutions, p = 3 ball, 10/3 roller Life in hours: L_10h = 10⁶·L_10 / (60·n) Reliability factor (ISO 281:2007, derived): a_1 = 0.95·[ln(100/R)/ln(100/90)]^(2/3) + 0.05 Modified life: L_nm = a_1·a_ISO·L_10 Static safety: P_0 = max(X_0·F_r + Y_0·F_a, F_r), s_0 = C_0/P_0
  Ref: ISO 281:2007 cl. 6–7 — Dynamic equivalent load and basic rating life
  Ref: ISO 281:2007 cl. 9 — Modified rating life
  Ref: ISO 76:2006 cl. 6–7 — Static equivalent load and static safety factor
  Ref: Shigley's Mechanical Engineering Design 11th ed., Ch. 11 — Rolling-contact bearings

2. INPUTS
  Symbol | Description | Value | Unit | Source | Valid range
  type | Bearing type | ball (p = 3) |  | manual | any
  F_r | Radial load | 2 | kN | manual | 0 … 2000 kN
  F_a | Axial load | 0 | kN | manual | 0 … 2000 kN
  n | Speed | 1000 | rpm | manual | 1 … 50000 rpm
  C | Basic dynamic load rating | 20 | kN | manual | 0.1 … 10000 kN
  C_0 | Basic static load rating | 11 | kN | manual | 0.1 … 10000 kN
  e_lim | Load ratio limit e | 0.3 |  | manual | 0 … 5
  X | Radial factor X | 1 |  | manual | 0 … 5
  Y | Axial factor Y | 0 |  | manual | 0 … 10
  X_0 | Static radial factor X₀ | 0.6 |  | manual | 0 … 5
  Y_0 | Static axial factor Y₀ | 0.5 |  | manual | 0 … 10
  R | Reliability | 95 | % | manual | 90 … 99.95 %
  a_iso | Life modification factor a_ISO (from the manufacturer's tool) | 1 |  | manual | 0.1 … 50

  s_0_req | Required static safety factor | 1 |  | manual | 0.5 … 4

3. ASSUMPTIONS
  A1. Ratings C and C₀, factors X, Y, e, X₀, Y₀ and a_ISO are the manufacturer's values for the bearing, entered as reference records. (No catalogue table ships with TempestOS (§A5).)
  A2. a₁ uses the ISO 281:2007 Weibull form (0.64 at 95 %, 0.25 at 99 %); ISO 281:1990 gave 0.62 and 0.21. (Edition stated on the sheet.)
  A3. Loads are steady within each duty step; speed is constant. (Duty steps weighted by share of revolutions.)

4. WORKING
  [16] p = 3    « ISO 281:2007 cl. 6–7
      = 3
        Life exponent, ball bearing
  [17] P = F_r    « ISO 281:2007 cl. 6–7
      = 2 kN
      = 2 kN
        Equivalent dynamic load (F_a/F_r ≤ e_lim)
  [18] P_0 = max(X_0 * F_r + Y_0 * F_a, F_r)    « ISO 76:2006 cl. 6–7
      = max(0.6 × 2 kN + 0.5 × 0 kN, 2 kN)
      = 2 kN
        Equivalent static load
  [19] L_10 = (C / P)^p    « ISO 281:2007 cl. 6–7
      = (20 kN / 2 kN)^3
      = 1000
        Basic rating life, million revolutions
  [20] L_10h = L_10 * 1000000 * 2 * pi / n
      = 1000 × 1000000 × 2 × π / 1000 rpm
      = 16667 h
        Basic rating life in hours
  [21] a_1 = 0.95 * (ln(1 / R) / ln(1 / 0.9))^(2 / 3) + 0.05    « ISO 281:2007 cl. 9
      = 0.95 × (ln(1 / 95 %) / ln(1 / 0.9))^(2 / 3) + 0.05
      = 0.63791
        Reliability factor (derived, ISO 281:2007 Weibull form)
  [22] L_nm = a_1 * a_iso * L_10    « ISO 281:2007 cl. 9
      = 0.63791 × 1 × 1000
      = 637.91
        Modified rating life, million revolutions
  [23] L_nmh = a_1 * a_iso * L_10h
      = 0.63791 × 1 × 16667 h
      = 10632 h
        Modified rating life in hours
  [24] s_0 = C_0 / P_0    « ISO 76:2006
      = 11 kN / 2 kN
      = 5.5
        Static safety factor
  [25] u_life = L_req / L_nmh
      = 10000 h / 10632 h
      = 0.94057
        Life utilisation (required / modified life)
  [26] u_s0 = s_0_req / s_0
      = 1 / 5.5
      = 0.18182
        Static utilisation (required / actual safety factor)
