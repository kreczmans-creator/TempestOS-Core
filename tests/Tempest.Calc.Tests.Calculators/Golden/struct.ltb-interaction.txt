Title: Lateral-torsional buckling and N+M interaction (EN 1993-1-1)

1. Scope and method
Calculates the lateral-torsional buckling, flexural buckling and bending-with-compression interaction of a uniform doubly-symmetric I-section member on fork supports, to EN 1993-1-1. Class 4 sections are outside this sheet.
Critical moment (NCCI SN003 form): M_cr = C₁·π²E·I_z/(kL)²·[√((k/k_w)²·I_w/I_z + (kL)²·G·I_t/(π²E·I_z) + (C₂z_g)²) − C₂z_g]; C₁ = 1.88 − 1.40ψ + 0.52ψ² ≤ 2.70 (end moments, k = 1) unless entered LTB slenderness: λ̄_LT = √(W_y·f_y/M_cr), W_y = W_pl,y (class 1, 2) or W_el,y (class 3) Lateral-torsional buckling, general case (6.3.2.2): Φ_LT = 0.5[1 + α_LT(λ̄_LT − 0.2) + λ̄_LT²]; χ_LT = 1/(Φ_LT + √(Φ_LT² − λ̄_LT²)) ≤ 1 Lateral-torsional buckling, rolled sections (6.3.2.3): Φ_LT = 0.5[1 + α_LT(λ̄_LT − λ̄_LT,0) + β·λ̄_LT²]; χ_LT = 1/(Φ_LT + √(Φ_LT² − β·λ̄_LT²)) ≤ 1, ≤ 1/λ̄_LT²; optional χ_LT,mod = χ_LT/f ≤ 1, ≤ 1/λ̄_LT² (eq. 6.58), f = 1 − 0.5(1 − k_c)[1 − 2(λ̄_LT − 0.8)²] ≤ 1 Buckling resistance in bending: M_b,Rd = χ_LT·W_y·f_y/γ_M1 Flexural buckling: N_cr = π²EI/L_cr², λ̄ = √(A·f_y/N_cr), Φ = 0.5[1 + α(λ̄ − 0.2) + λ̄²], χ = 1/(Φ + √(Φ² − λ̄²)) ≤ 1, N_b,Rd = χ·A·f_y/γ_M1; the curve of each axis from Table 6.2 (section type, h/b, t_f; f_y ≤ 420 MPa) or chosen Interaction (6.3.3(4)): N_Ed/(χ_y·N_Rk/γ_M1) + k_yy·M_y,Ed/(χ_LT·M_y,Rk/γ_M1) + k_yz·M_z,Ed/(M_z,Rk/γ_M1) ≤ 1; N_Ed/(χ_z·N_Rk/γ_M1) + k_zy·M_y,Ed/(χ_LT·M_y,Rk/γ_M1) + k_zz·M_z,Ed/(M_z,Rk/γ_M1) ≤ 1 Factors k_ij: Annex B from the slenderness, N_Ed/(χ·N_Rk/γ_M1) and C_m (C_m = 0.6 + 0.4ψ ≥ 0.4 for a linear diagram, or entered); Annex A from the μ, w, n_pl, a_LT and C_ij expressions (class 1, 2: plastic column of Table A.1; class 3: elastic column, without the 0.6√(w_i/w_j) factors of k_yz, k_zy)

3. Assumptions
  A1. The member is uniform, doubly symmetric and on fork supports, free to warp and to rotate about the minor axis. (Mono-symmetric, tapered and cantilever members and continuous restraint are not modelled.)
  A2. A k or k_w below 1 models partial restraint of the end rotation or of the warping. (The factors k and k_w are entered, not derived.)
  A3. The cross-section class is the class the user states, 1, 2 or 3. (Effective properties of class 4 sections are not derived.)
  A4. The factor C₁ from the ψ formula applies to end-moment diagrams with k = 1. (For other diagrams the user enters C₁, C₂, k_c and C_my from the source in use.)
  A5. No table of C₁ or C₂ values is shipped, so the user takes them from the source in use. (The factors are stored as reference records.)
  A6. The imperfection factors, β and λ̄_LT,0 default to the recommended values, which the National Annex may change. (They are a factor set the user can verify.)
  A7. The 2022 edition choice changes the printed label only, and the arithmetic stays that of the 2005+A1:2014 edition. (The differences between the editions cannot be stated with certainty, and the sheet warns.)
  A8. The flexural buckling curves chosen automatically are those of Table 6.2 for S 235 to S 420. (For a higher f_y or a combination without a row the user chooses the curve.)
  A9. The Annex A and Annex B expressions are implemented as published. (The user checks their coefficients against the owner's copy of the standard.)
